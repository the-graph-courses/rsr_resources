Variable glossary

Main fields for this EDA

SEQN ID

Respondent sequence number. Merge key between DEMO_G and CFQ_G.

RIDAGEYR Sociodemographic

Age in years at screening. CFQ sample is ages 60–80 (80 = 80 and over).

RIAGENDR Sociodemographic

Sex: 1 = Male, 2 = Female.

DMDEDUC2 / RIDRETH3 Sociodemographic

Adult education level and race/Hispanic origin (2011–2012 coding with Asian category).

CFDAST Outcome

Animal Fluency score: number of animals named in 60 seconds. Higher = better verbal / categorical fluency.

CFDAPP Eligibility

Practice pretest (name 3 clothing items). Score available only if Passed (1).

CFDDS / CERAD vars Other outcomes

Digit Symbol Substitution Test total (CFDDS) and CERAD word-learning / delayed recall scores.

WTMEC2YR Weight

MEC examination 2-year sample weight. Use for population-representative estimates (cognition was done in the MEC).

Source: CDC NHANES 2011–2012 · CFQ_G docs · DEMO_G docs
