Simple linear regression with a polytomous predictor

For a categorical predictor with more than two levels, R uses K − 1 dummy variables. You will fit models, read the coefficients, and change the reference level.

Overview

A polytomous predictor has \(K > 2\) categories, such as race with three groups or treatment dose with three groups. If the groups are categories, avoid coding them as one numeric variable unless you want to assume a single straight-line trend.

Instead, R picks one reference level and creates one dummy variable for each of the other \(K - 1\) levels. Each coefficient is that level’s mean difference vs the reference.

This practical uses datasets available in WebR:

  • ToothGrowth: tooth length (len) by vitamin C dose (3 levels)
  • MASS::birthwt: birth weight (bwt) by mother’s race (3 levels)
  • PlantGrowth: plant weight (weight) by treatment group (3 levels)
  • InsectSprays: insect count (count) by spray type (6 levels)

Question 2

Why might you convert dose to a factor instead of using one numeric dose column?

The equation (three dose levels, 0.5 mg reference)

\[\hat{y} = b_0 + b_1 \cdot \text{dose 1 mg} + b_2 \cdot \text{dose 2 mg}\]

  • Each dummy equals 1 only for its own level and 0 otherwise.
  • \(b_0\) = mean of the reference group (0.5 mg dose).
  • Each \(b_j\) = that level’s mean minus the reference mean.
  • To recover a group’s mean: add its coefficient to the intercept (reference groups add 0).

Choosing the order and reference level

The first factor level is the reference. Choose the level order to match how you want to read the model output:

  • Natural order: lowest dose level, so effects read as changes from the low-dose group.
  • Outcome order: group levels ordered from lowest to highest outcome mean, so coefficients read as increases from the lowest group.
  • Clinical control: placebo or standard care, so every coefficient is a treatment effect.
  • Largest group: can yield tighter confidence intervals because the reference mean is estimated precisely.
