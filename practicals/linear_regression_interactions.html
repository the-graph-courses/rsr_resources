Interaction terms in linear regression

An interaction term lets the effect of one predictor depend on the value of another. This practical fits an interaction with a binary predictor and then with a categorical predictor that has several levels, and reads each group’s slope from the coefficient table.

Overview

An additive model assumes the slope of a predictor is the same at every level of the other predictors:

lm(outcome ~ x + group, data = my_data)

An interaction model lets that slope change with the other predictor. In R you write the interaction with a colon, adding it to the two main effects:

lm(outcome ~ x + group + x:group, data = my_data)

R also has a shorthand, x * group, that expands to the same three terms. This practical uses the explicit form above so that every term you fit is visible.

The main skill in this practical is reading each group’s own slope from the coefficient table. You will:

  • Fit an interaction with a binary predictor and read the reference and non-reference slopes.
  • Extend to a categorical predictor with more than two levels (a polytomous predictor).

Reading the two slopes

The coefficient table does not give each group’s slope directly. You build them. The reference group (no) uses the plain BMI row. The other group adds the interaction row to it.

Building each group’s line from the four coefficients
Group Intercept BMI slope
no (reference) 87.64 1.70
yes 87.64 + 57.11 = 144.75 1.70 + (−0.99) = 0.71

The BPMedsyes coefficient (57.11) shifts the intercept. The BMI:BPMedsyes coefficient (−0.99) shifts the slope. Among people on medication, the association between BMI and systolic BP is much flatter.

Question 3

Predict the systolic BP for a person on medication with BMI = 30. Use the intercept and slope for the medication group.

The interaction equation. With g = 1 for the medication group and 0 for the reference group:

\[ \widehat{\text{sysBP}} = b_0 + b_1\,\text{BMI} + b_2\,g + b_3\,(\text{BMI}\times g) \]

The reference slope is b1. The non-reference slope is b1 + b3. The next part applies the same rule to a predictor with more than two levels.

Part 2. A polytomous categorical predictor

Now the grouping variable has more than two levels. The idea does not change. R picks one level as the reference and gives every other level its own main-effect row and its own interaction row.

We use ChickWeight, a built-in R dataset from an experiment in which chicks were raised on four protein diets and weighed repeatedly over 21 days. The question is whether the growth rate depends on the diet.

  • Outcome: weight (body weight, grams)
  • Continuous predictor: Time (days since birth)
  • Categorical predictor: Diet with four levels: 1 (reference), 2, 3, 4

Reading four slopes from one table

Same rule as before, repeated for each non-reference level. The reference level (Diet 1) uses the plain Time row. Each other level adds its own Time:Diet_ interaction row.

Each diet gets its own intercept and its own growth slope
Group Intercept Time slope (g per day)
Diet 1 (reference) 30.931 6.842
Diet 2 30.931 + (−2.297) = 28.634 6.842 + 1.767 = 8.609
Diet 3 30.931 + (−12.681) = 18.250 6.842 + 4.581 = 11.423
Diet 4 30.931 + (−0.139) = 30.792 6.842 + 2.873 = 9.715

Chicks gain weight over time on every diet, but they grow fastest on Diet 3 (11.42 g/day) and slowest on Diet 1 (6.84 g/day). The diets start at similar weights and the lines spread apart over time. That difference in slopes is the interaction.

A note on interactions between two continuous variables

Every interaction in this practical involves one continuous variable and one categorical variable. You can also fit an interaction between two continuous variables, for example lm(sysBP ~ BMI + age + BMI:age, data = fram). This is uncommon in public health and health statistics, where interactions are usually examined across categorical groups such as treatment arm, sex, or age bands.

When you do fit one, there is no small set of groups to tabulate. Instead, the slope of one variable becomes a straight-line function of the other, and a common way to interpret it is to read that slope at a few chosen values of the second variable (for example a low, middle, and high value).
