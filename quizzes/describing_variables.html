A researcher creates a table showing the number and percentage of participants in each smoking-status group. Which branch of statistics is this?

This summarises the data in the sample. It does not test a hypothesis or estimate an unknown population value, so it belongs to descriptive statistics.

A survey includes 971 people from an urban district in Cameroon to learn about COVID-19 antibody prevalence in that district. What is the sample?

The sample is the group actually studied. The population is the wider group we want to learn about, and the true prevalence is the unknown parameter we want to estimate.

In a dataset, what does a variable usually correspond to?

A variable is usually stored as a column. Each row is an observation, and each cell contains a value.

The is_drug_* columns were imported as numeric (dbl). What do these 0/1 values actually represent?

A 0/1 column often encodes a binary yes/no flag, even though R imports it as numeric (dbl). Converting with as.logical() makes the meaning explicit and stops these columns being treated as measurements.

What does this code do?

yaounde <- yaounde %>%
  mutate(across(starts_with("is_drug"), as.logical))
starts_with("is_drug") selects the drug indicator columns, and as.logical() converts their 0/1 values into FALSE/TRUE.

What does the levels argument do in this factor() call?

  age_category_3,
  levels = c("child", "adult", "senior")

Setting levels tells R the inherent order of an ordinal variable. ggplot2 and other tools will then respect that order on axes and legends.

What does position = "dodge" do in this bar chart?

ggplot(yao, aes(x = is_smoker, fill = sex)) +
  geom_bar(position = "dodge")
Dodging places subgroup bars next to each other, which makes raw subgroup counts easier to compare directly. Stacking is the default, and rescaling to 100% is position = "fill".

Each geom_* function produces a different chart. geom_histogram() bins a continuous variable, geom_bar() counts categorical values, geom_boxplot() shows quartiles, geom_density() smooths the distribution, and geom_violin() shows density shape on both sides of a centre line.

The plot below shows a histogram with a smooth orange curve drawn on top. What does the orange curve represent?

A density curve is a smoothed distribution estimate. It does not pass through the bar tops exactly, and it shows distribution shape rather than counts or running totals.

In the box plot below, match each labelled feature (A, B, C, D) to what it represents.

Outlier (a point beyond 1.5 × IQR from the box)
First quartile (25th percentile, left edge of the box)
Median (50th percentile, line inside the box)

A box plot is a five-number summary: the box spans Q1 to Q3 (the IQR), the inner line marks the median, and the whiskers reach the most extreme points within 1.5 × IQR. Anything further out is plotted as an outlier point.

The interquartile range (IQR) of a numeric variable is:

IQR is Q3 minus Q1 and contains the middle 50% of the data. It also defines the length of the box in a box plot.
