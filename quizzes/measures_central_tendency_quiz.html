The sum of 12 BMI measurements is 318. What is the mean BMI?

n = 12  ·  Σx = 318
The mean is the sum of values divided by the count: 318 / 12 = 26.5. You do not need each individual value to compute the mean, only the total and how many observations contributed to it.

The BMI values below have already been sorted. What is the median?

23, 24, 27, 28already sorted from smallest to largest
With an even number of values, the median is the average of the two middle values. Here the middle two are 24 and 27, so the median = (24 + 27) / 2 = 25.5.

What is the median of these BMI values?

27, 22, 24, 18, 26
Always order the data first: 18, 22, 24, 26, 27. With 5 values, the median is the (5+1)/2 = 3rd value, which is 24.

Match each property to the measure of central tendency it best describes.

May not exist if all values in the dataset are unique
Calculated as the sum of values divided by the count of values
Most sensitive to outliers and skewness

The mean is calculated by summing and dividing, which makes it sensitive to extreme values. The median is robust because it depends only on the middle of the ordered data. The mode is the most frequent value: it always lies on a real observation, and it might not exist if every value is unique.

Unimodal datasets have exactly one most-frequent value. Multimodal datasets have two or more values tied as most frequent. Datasets with all-unique values have no mode.

Base R has mean() and median() functions, but not a function for the statistical mode. Which function should you use instead?

Base R does have a function named mode(), but it returns the storage type of an object (e.g., "numeric"), not the statistical mode. DescTools provides Mode() with a capital M, which returns the most frequently occurring value.

This code throws an unexpected result. What is the most likely fix?

mode(yao$height_cm)
[1] "numeric"
R is case-sensitive. Lowercase mode() in base R returns the storage type of an object. Capital Mode() from DescTools returns the statistical mode.

Which of these might explain why this code returns NA?

mean(yao$n_bedridden_days)
[1] NA
Base R's mean(), median(), and DescTools::Mode() all return NA when their input contains any NA values. Add na.rm = TRUE inside the call to drop missing values before calculating: mean(yao$n_bedridden_days, na.rm = TRUE).

A dataset of household incomes contains many low-to-mid earners and one extremely high outlier (a millionaire). Which measure of central tendency is most affected by this outlier?

The mean is computed using the magnitude of every value, so a single very large value pulls it noticeably upward. The median and mode depend only on positions or frequencies of values, not their magnitudes, so they are far more robust to outliers.

In symmetric distributions, all three measures coincide. In right-skewed distributions, the long right tail pulls the mean rightward, giving mode < median < mean. In left-skewed distributions, the long left tail pulls the mean leftward, giving mean < median < mode.
