2
Binary outcome: weak grip

Code weak_grip = 1 if grip ≤ 27 kg, else 0.

klosa <- klosa |>
  mutate(weak_grip = as.integer(grip <= 27))

Points now take one of two values: 1 (weak) and 0 (not weak).

Cut the dot plot into five-year age bands.

age_bands <- klosa |>
  mutate(age_band = cut(age,
    breaks = c(seq(45, 85, 5), Inf), right = FALSE)) |>
  group_by(age_band) |>
  summarise(age_mid = mean(age),
    prop_weak = mean(weak_grip), .groups = "drop")

Group into age bands and calculate the proportion with weak grip. Each proportion estimates a probability.

One idea that does not work well: fit a straight line through.

band_lm <- lm(prop_weak ~ age_mid, data = age_bands)
summary(band_lm)
#>             Estimate Std. Error t value Pr(>|t|)
#> (Intercept) -0.97688    0.10611   -9.21  3.68e-05 ***
#> age_mid      0.01958    0.00156   12.56  4.67e-06 ***
$\widehat{\Pr(\text{weak grip})} = -0.97688 + 0.01958\,(\text{age})$

Problem 1: the line predicts probabilities below 0 or above 1. Problem 2: a straight line does not capture the right shape.

1. The fitted line predicts a probability of weak grip below zero for younger men. What is wrong with that?

A. Probabilities must lie between 0 and 1B. The slope should be negative, not positive

Logistic regression
S-curve for the probability of weak grip.

Fit a logistic regression.

weak_glm <- glm(weak_grip ~ age, family = binomial, data = klosa)
summary(weak_glm)
#>             Estimate Std. Error z value Pr(>|z|)
#> (Intercept) -8.82431    0.31925  -27.64   <2e-16 ***
#> age          0.11683    0.00476   24.57   <2e-16 ***
$p = \dfrac{1}{1 + e^{-(\beta_0 + \beta_1\,\text{age})}}$
$\widehat p = \dfrac{1}{1 + e^{-(-8.82431 + 0.11683\,\text{age})}}$

1. Can this logistic equation produce a probability greater than 1?

A. YesB. No

2. Who has the higher predicted probability of weak grip?

A. A 50-year-oldB. An 80-year-old

3. If $\beta_1=0$, the predicted probability would:

A. Stay constant across ageB. Increase with age
  • Regression helps us predict and understand effects.
  • Prediction is easy: substitute age to obtain a predicted probability.
  • Understanding (and explaining) effects: Harder! There is no fixed probability change for a one-year increase in age.
  • Instead, each year adds a fixed $\beta_1$ to the log odds.
