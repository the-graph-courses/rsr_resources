2
Binary outcome: weak grip
Same men. Outcome is 0 or 1 only.
  • Same men, ages, and grip values. The 27 kg cutoff is shown again.
  • Code weak_grip = 1 if grip ≤ 27 kg, else 0.
  • The mean of a 0/1 variable is the proportion with weak grip.
  • Points now occupy two rows: 1 (weak) and 0 (not weak).
  • Distance from the 27 kg cutoff is no longer retained.
  • Fit lm(weak_grip ~ age): a linear probability model.
  • A straight line is not suitable for this outcome.
  • The line can predict values below 0 or above 1.
  • It does not respect the range of a probability.
  • Group into age bands and calculate the proportion with weak grip.
  • Each proportion estimates a probability.

3
Age-band proportions
A straight line through probabilities fails.
  • Weak grip rises from about 3% (youngest) to 79% (oldest).
  • Fit a straight line through these proportions. Check the ends and the constant slope.
  • Problem 1: it leaves [0, 1]. Problem 2: same change at every age.
  • The data rise slowly, then faster, then slowly again.
4
Logistic regression
S-curve for the probability of weak grip.
  • Logistic regression models log-odds as a straight line in age.
  • On the probability scale, the curve stays inside [0, 1].
  • R: glm(weak_grip ~ age, family = binomial).
  • Coefficients are on the log-odds scale.
  • The fitted curve stays inside [0, 1] and follows the age-band proportions.
  • Interpreting the age coefficient is the next lesson.
R# logistic regression (binomial GLM) glm(weak_grip ~ age, family = binomial, data = klosa) #> Estimate Std. Error z value Pr(>|z|) #> (Intercept) -8.82431 0.31925 -27.64 <2e-16 *** #> age 0.11683 0.00476 24.57 <2e-16 ***
