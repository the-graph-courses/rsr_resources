The likelihood-ratio test

Suppose age had no real effect. The drop would still not be zero.

Its distribution is known: chi-squared, df = number of added parameters.

The 5% cutoff is 3.84. Our drop is 803.8 — far beyond it.

anova(m0, m1, test = "LRT")
#> Model 1: weak_grip ~ 1
#> Model 2: weak_grip ~ age
#>   Resid. Df Resid. Dev Df Deviance  Pr(>Chi)
#> 1      4183     4259.0
#> 2      4182     3455.1  1   803.85 < 2.2e-16 ***

Comparing models with anova()
klosa2 <- klosa |> drop_na(bmi, smoking)   # 4,134 men
m1 <- glm(weak_grip ~ age, family = binomial, data = klosa2)
m2 <- glm(weak_grip ~ age + bmi, family = binomial, data = klosa2)
m3 <- glm(weak_grip ~ age + bmi + smoking,
          family = binomial, data = klosa2)

Compare models only on the same rows — so remove missing BMI / smoking first.

Model choice
AIC: deviance plus a penalty for parameters

Deviance always goes down when we add terms.

So deviance alone cannot choose between models.

$\mathrm{AIC} = \text{residual deviance} + 2k$

k = number of parameters. A term helps only if it removes more than 2 deviance per parameter.

m0 <- glm(weak_grip ~ 1, family = binomial, data = klosa2)
AIC(m0, m1, m2, m3)
#>    df      AIC
#> m0  1 4153.704
#> m1  2 3385.656
#> m2  3 3309.037
#> m3  5 3310.474

smoking removes 2.56 deviance but adds 2 parameters: +4. AIC goes up.

Lowest AIC: m2 (age + bmi).

Differences under 2 are ties. Then choose the simpler model.

AIC can also compare non-nested models. The LRT cannot.
