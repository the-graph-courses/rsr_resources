KLoSA Wave 1 (2006) · 4,184 Korean men aged 45+ · grip strength by hand dynamometer

From a straight line to an S‑curve: the idea behind logistic regression

1 · A question we already know
Measure each man’s grip strength at his age. Every dot is one person — age across, grip up. We can fit a straight line through the cloud.
$\text{grip} = 55.7 - 0.382\,(\text{age})$
One slope for the whole line. Each extra year costs about 0.38 kg — and it is the same step from 50→51 as from 80→81. In linear regression the change is constant.
2 · But suppose the question is yes / no
Often we don’t need the exact kilograms — clinicians set a cutoff for low grip (here ≤ 27 kg). Recode each man to 1 = weak, 0 = not.
R
klosa <- klosa |> mutate(
  weak_grip = as.integer(grip <= 27))
Just 0s and 1s — the trend is hard to see.
So group age into bands and take the % weak in each. The mean of a 0/1 column is a proportion — a probability.
3 · So — run a straight line through it?
Two things go wrong

1. A line never stops — extend it and it predicts a probability below 0% or above 100%. But probability is trapped in [0, 1].

2. A line adds the same step everywhere. But probability moves slowly near 0, faster in the middle, then slowly again as it nears 1.

We want a curve that (a) stays inside [0, 1], (b) rises or falls smoothly, and (c) flattens at both ends.
4 · Bend it into an S‑curve
$p = \dfrac{1}{1 + e^{-x}}$
Whatever we feed in for $x$, the result lands between 0 and 1: big negative → 0,  $x=0$ → 0.5,  big positive → 1.
Now put the regression line inside, in place of $x$:
$p = \dfrac{1}{1 + e^{-(\beta_0 + \beta_1\,\text{age})}}$
R
glm(weak_grip ~ age,
    family = binomial, data = klosa)
Software chooses $\beta_0,\beta_1$ so the observed 0s and 1s are as likely as possible. Inside every logistic curve sits an ordinary straight line — how to read $\beta_1$ is the next lesson.
