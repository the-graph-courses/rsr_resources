$L_i = \begin{cases} p_i & y_i = 1 \\[2pt] 1-p_i & y_i = 0 \end{cases}$

Each $L_i$ is that student's likelihood contribution.

$L = \displaystyle\prod_{i=1}^{n} L_i = \prod_{i=1}^{n} p_i^{y_i}(1-p_i)^{1-y_i}$
$L = .954 \times .861 \times .353 \times .353 \times .861 \times .954 = 0.084$

glm() chose the coefficients using maximum likelihood estimation (MLE).

R uses Fisher scoring to update the coefficients. "Number of Fisher Scoring iterations: 5" indicates five iterations.

Multiplying many small numbers is difficult to work with. Logs turn that product into a sum.

$\ell = \ln L = \ln(.954)+\ln(.861)+\ln(.353)+\ln(.353)+\ln(.861)+\ln(.954) = -2.478$
$\ell = -0.047-0.150-1.041-1.041-0.150-0.047 = -2.478$
logLik(mod)   #> 'log Lik.' -2.477987 (df=2)

Deviance
$\text{Deviance} = -2 \times \text{log-likelihood}$
$\text{Residual deviance} = -2 \times (-2.478) = 4.956$

The main reason for the −2: differences in deviance between nested models follow a chi-squared distribution.

Null deviance comes from a model with no predictors.

That model predicts 0.5 for everyone, because 3 of 6 students passed.

$\ell_0 = 6\times\ln(0.5) = 6\times(-0.693) = -4.159$
$\text{Null deviance} = -2\times(-4.159) = 8.318$

Null deviance = deviance of the intercept-only model.

Residual deviance = deviance of the fitted model.

Degrees of freedom = number of observations − number of parameters.
