Same ideas, now on KLoSA men aged 45+: weak grip predicted from age.

klosa <- read_csv("klosa_men_grip_45plus.csv")   # 4184 men
m0 <- glm(weak_grip ~ 1,   family = binomial, data = klosa)
m1 <- glm(weak_grip ~ age, family = binomial, data = klosa)
#> summary(m1) shows:
#>     Null deviance: 4259.0  on 4183  degrees of freedom
#> Residual deviance: 3455.1  on 4182  degrees of freedom
#> AIC: 3459.1

Flat dashed line: the null model. It predicts 0.206 for everyone (overall weak-grip rate).

Gold curve: the model with age. Teal dots: observed proportion at each age.

$\text{Deviance drop} = 4259.0 - 3455.1 = 803.9$

Adding any predictor reduces deviance a little, even a useless one.

So residual deviance alone cannot choose between models. We need a score that also penalizes complexity.

AIC: deviance plus a penalty for parameters

Deviance always goes down when we add terms.

So deviance alone cannot choose between models.

$\mathrm{AIC} = \text{residual deviance} + 2k$

k = number of parameters. A term helps only if it removes more than 2 deviance per parameter.

m0 <- glm(weak_grip ~ 1, family = binomial, data = klosa)
m1 <- glm(weak_grip ~ age, family = binomial, data = klosa)
m2 <- glm(weak_grip ~ age + diabetes, family = binomial, data = klosa)
m3 <- glm(weak_grip ~ age + diabetes + hypertension,
          family = binomial, data = klosa)
AIC(m0, m1, m2, m3)
#>    df      AIC
#> m0  1 4260.9918
#> m1  2 3459.1460
#> m2  3 3441.1124
#> m3  4 3443.1104

hypertension removes almost no deviance but adds 1 parameter: +2. AIC goes up by about 2.

Lowest AIC: m2 (age + diabetes).

There is no “good” AIC number. Only differences on the same outcome and same rows matter.

Differences under 2 are ties. Then choose the simpler model.
