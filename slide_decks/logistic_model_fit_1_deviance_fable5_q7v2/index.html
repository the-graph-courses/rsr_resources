Each dot is one man in the data, at 1 (weak grip) or 0 (not weak).

The gold curve is the fitted model. The change in probability per year is not the same everywhere: small at young ages, larger in the middle, and small again at old ages.

$p = \dfrac{1}{1 + e^{-(\beta_0 + \beta_1\,\text{age})}}$
$\widehat p = \dfrac{1}{1 + e^{-(-8.824 + 0.1168\,\text{age})}}$

The age coefficient $\beta_1 = 0.1168$ is a change in the log-odds per year, not in probability. Below the coefficients, summary() also prints null deviance, residual deviance, and AIC. That is what this lesson explains.

Small example
Scoring the model's predictions

Six students, one exam. Each dot: 1 = passed, 0 = failed.

hours <- c(1, 2, 3, 4, 5, 6)
pass  <- c(0, 0, 1, 0, 1, 1)
mod <- glm(pass ~ hours, family = binomial)
coef(mod)   #> intercept -4.249,  hours 1.214

Gold curve: predicted P(pass). Green area below it: probability of passing.

Red area above the curve: probability of failing. Green + red = 1.

$\text{passed: score} = P(\text{pass}) \qquad \text{failed: score} = P(\text{fail}) = 1 - p$

A failed: score 0.954. D failed: score only 0.353.

$L = .954 \times .861 \times .353 \times .353 \times .861 \times .954 = 0.084$

This product is the likelihood. Higher = better fit.

Small example
From scores to deviance

With thousands of people, the product becomes too small to store.

So we add logarithms of the scores instead.

The table adds ln(score) over all six students.

logLik(mod)   #> 'log Lik.' -2.477987 (df=2)
$\text{Deviance} = -2 \times \text{log-likelihood}$
$-2 \times (-2.478) = 4.956$

Lower deviance = better fit. A perfect model has deviance 0.

The ×(−2) makes deviance differences follow a chi-squared distribution (next lesson).

Now a model with no predictors:

mod0 <- glm(pass ~ 1, family = binomial)
fitted(mod0)   #> 0.5 0.5 0.5 0.5 0.5 0.5

It predicts 0.5 for everyone, because 3 of 6 passed.

Null deviance = deviance of the no-predictor model.

Residual deviance = deviance of your model.

Degrees of freedom = number of people − number of model parameters.

Real data
The same table, with 4,184 men

Null deviance 4259.0: the model without age.

Residual deviance 3455.1: the model with age.

$\mathrm{AIC} = \text{residual deviance} + 2 \times \text{number of parameters}$
$\mathrm{AIC} = 3455.1 + 2 \times 2 = 3459.1$

AIC is used to compare models. More on this next lesson.

Adding age reduced the deviance by 803.8.

Is this reduction more than chance? Next lesson: the likelihood-ratio test.
