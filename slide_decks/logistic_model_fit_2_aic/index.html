anova(m_age, test = "LRT")
#>      Df Deviance Resid. Df Resid. Dev Pr(>Chi)
#> NULL                  4183     4259.0
#> age   1   803.85      4182     3455.1  <2e-16 ***

Information from an LRT often overlaps with whether coefficients are significant in summary(), so we leave it aside here. Unlike AIC, the standard LRT compares nested models only.

Adding predictors almost always lowers residual deviance, even when they are useless. So we need to balance better fit against added complexity. That is the job of AIC.

AIC rewards fit and penalizes complexity

Akaike Information Criterion (AIC) plays a role similar to adjusted R²: both reward fit while penalizing extra parameters.

$\mathrm{AIC} = \text{residual deviance} + 2k$

Here, k counts coefficients including the intercept. Lower AIC is preferred.

AIC also works for linear models; we will cover that formula in another lesson.

set.seed(2026)
klosa <- klosa |> mutate(
  age_group = cut(age, c(45, 65, 75, Inf), include.lowest = TRUE),
  noise = rnorm(n()))
m0      <- glm(weak_grip ~ 1, family = binomial, data = klosa)
m_age   <- glm(weak_grip ~ age, family = binomial, data = klosa)
m_noise <- glm(weak_grip ~ age + noise, family = binomial, data = klosa)
m_group <- glm(weak_grip ~ age_group, family = binomial, data = klosa)
deviance(m0); deviance(m_age); deviance(m_noise); deviance(m_group)
AIC(m0, m_age, m_noise, m_group)
#>           df deviance    AIC
#> m0         1   4259.0 4261.0
#> m_age      2   3455.1 3459.1
#> m_noise    3   3454.8 3460.8
#> m_group    3   3603.9 3609.9

An AIC of 3459.1 is not good or bad on its own.

AIC becomes meaningful only when we compare candidate models.

AIC is not a p-value and has no universal good/bad cutoff.
