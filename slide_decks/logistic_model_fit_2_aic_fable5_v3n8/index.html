Two lines you can now read — and one we have not explained yet: AIC.

Red dashed line: the null model. It predicts 0.201 for everyone.

Gold curve: the model with age. Deviance drop: 4151.7 − 3381.7 = 770.0.

Adding any predictor reduces deviance a little, even a useless one.

AIC: deviance plus a penalty for parameters

Deviance always goes down when we add terms. So we make every term pay rent:

$\mathrm{AIC} = \text{residual deviance} + 2k$

k = number of parameters. A term helps only if it removes more than 2 deviance per parameter. Lower AIC is better.

m2 <- glm(weak_grip ~ age + bmi, family = binomial, data = men)
m3 <- glm(weak_grip ~ age + bmi + smoking,
          family = binomial, data = men)
AIC(m0, m1, m2, m3)
#>    df      AIC
#> m0  1 4153.704
#> m1  2 3385.656
#> m2  3 3309.037
#> m3  5 3310.474

bmi removed 78.6 deviance for 1 extra parameter — it pays its way. AIC drops.

smoking removed only 2.6 but added 2 parameters (three levels → two coefficients). Penalty +4, so AIC rises by 1.4.

Lowest AIC: m2 (age + bmi). m3 sits only 1.4 above it — under 2 counts as a tie, and ties go to the simpler model.

Reading AIC: only differences matter

AIC has no absolute scale. There is no “good AIC” the way an R² of 0.6 is decent.

Only differences between models fitted to the same data mean anything.

ΔAIC under ~2: essentially tied — choose the simpler model.

ΔAIC over ~10: the higher-AIC model has essentially no support.

Compare only models with the same outcome, fitted to the same rows. Vary only the predictors.

The models do not need to be nested: weak_grip ~ age vs weak_grip ~ bmi is a fair comparison.

m_lin <- lm(grip ~ age + bmi, data = men)  # grip in kg
AIC(m_lin)   #> 26010.93

Least squares is maximum likelihood in disguise — so linear models have an AIC too, with the same rules.

But 26,010.9 vs 3,309.0 means nothing: grip (kg) and weak_grip (0/1) are different outcomes.

What AIC is for — and what it is not for

Use it for: comparing a few candidate models you planned in advance.

Typical choices: keep an interaction or not; enter age as a straight line or as age groups.

Not for: letting AIC search every combination of variables. That biases coefficients and p-values.

Causal question (“does smoking cause weak grip?”)? Choose confounders with subject-matter knowledge — not with AIC.

Report: “We compared four pre-specified models of weak grip; the model with age and BMI had the lowest AIC (3309.0).”

Formuladeviance + 2kk = number of parameters. Each parameter must earn back its penalty of 2.
Directionlower = betterThe raw value has no meaning — only differences do.
