SUNSHINE and SHIN

We created an acronym (SUNSHINE) to help you remember the eight checks you should keep in mind when fitting a linear regression model.

  • S (Sample size): do you have enough observations for the model?
  • U (Uncorrelated errors): are the residuals uncorrelated across observations (no patterns by time or space order)?
  • N (No multicollinearity): are the predictors free of strong correlations with each other?
  • S (Shape / linearity): is the relationship actually a straight line?
  • H (Homogeneity of variance): does the spread of residuals stay constant?
  • I (Influential points): is the fit stable if you drop any single point?
  • N (Normality of residuals): are the prediction errors roughly bell-shaped?
  • E (Exogeneity): are the predictors unrelated to anything the model left out?

This script focuses on SHIN (Shape, Homoscedasticity, Influential points, and Normality), because those are the four assumptions you can check directly in R with check_model().

For multiple linear regression (two or more predictors), SHIN still applies, and you also need the other N: No multicollinearity. That check only matters when you have more than one predictor.

Simple linear regression: one continuous predictor

Each section below walks through one SHIN check with a single continuous predictor: a good example, a bad example, then a practice question.

S: Shape (Linearity)

The question: is the relationship actually a straight line?

For simple linear regression, you can often spot a curved pattern in a scatterplot of the outcome versus the single predictor. That is why the examples below start with a scatterplot.

So why bother with the Linearity panel in check_model()? Two reasons. First, the diagnostic plot summarizes the pattern in the residuals after the line is fitted, which can make a subtle bend easier to see. Second, and more importantly for this course, scatterplots only work when you have one continuous predictor. As soon as you move to multiple linear regression, there is no single scatterplot that represents the whole model. The diagnostic plots are how you check shape in that setting too.

H: Homoscedasticity (Equal Variance)

The question here is: does the spread of the residuals stay constant across the range?

For this, we read the Homogeneity of variance panel (scale-location).

A flat green line means even spread. If the line slopes upward, then the spread of the residuals increases with the fitted value.

I: Influential Points

The question here is: is any single observation pulling the line around?

For this, we read the Influential observations panel (residuals vs leverage).

Points that sit outside the dashed contour combine an unusual x-value (leverage) with a large residual (off the line).

Multiple linear regression: no multicollinearity

When you have two or more predictors, check that they are not too strongly related to each other.

The question: can each predictor’s slope be estimated separately, or do the predictors overlap so much that the model cannot tell their individual effects apart?

Use check_collinearity() from the performance package. It reports the variance inflation factor (VIF) for each predictor. As a rule of thumb, VIF above about 5 suggests problematic overlap. (Some sources use 10 as the cutoff.)

The SHIN checks above still apply to multiple regression: check_model() works the same way for homoscedasticity, influential points, and normality. This section covers the extra check that only arises with multiple predictors.

N: No multicollinearity (low overlap among predictors)

Categorical polytomous predictor

A polytomous predictor has three or more levels (for example, three treatment groups).

Regression with one polytomous categorical predictor is the same model as a one-way ANOVA. The model is just comparing group means.

That means the assumptions are the same ones you learned for ANOVA:

  • observations are independent
  • each group’s residuals are roughly normal
  • the groups have similar spread

In this lesson, check_model() helps us check the last two: normality of residuals and homogeneity of variance.

The fitted line connects the group means. Within each group, every observation has the same x-value (its group code).

Shape (linearity) is not a meaningful check here. The line passes through the group means, so there is no curvature to assess.

Influential points are not meaningful either. Every observation in a group shares the same x-value, so no point can have unusual leverage. A large outcome value is an outlier, not an influential point in the sense used above.

Only H (homogeneity of variance) and N (normality of residuals) apply.

With three or more groups, the homogeneity panel in check_model() behaves as expected.

The Linearity and Influential observations panels still appear in the default output, but you can hide them with the check argument. For example, check = c("homogeneity", "normality") shows only the two panels you need.

H: Homoscedasticity (Equal Variance)

The question here is: is the spread of the outcome similar in each group?

For this, we read the Homogeneity of variance panel.

A flat green line means even spread across groups.

Categorical binary predictor

A binary predictor has exactly two levels (for example, exposed vs. unexposed).

Regression with one binary categorical predictor is the same model as an independent-samples t-test. The regression coefficient is the difference between the two group means.

So the assumptions are the same as for the usual pooled t-test:

  • observations are independent
  • residuals are roughly normal within each group
  • the two groups have similar spread

This is why we focus on H and N below. If you use Welch’s t-test, that version relaxes the equal-variance assumption, but ordinary lm() uses the pooled-variance version unless you deliberately change the standard errors.

The same reasoning as above applies: Shape and Influential points are not meaningful checks.

Only H and N apply.

The default check_model() output still includes all four SHIN panels. Use check = c("homogeneity", "normality") to show only the two that apply.
