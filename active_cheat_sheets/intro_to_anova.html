Intro to Statistical Tests: One-Way ANOVA

Comparing three or more group means with a single F-test instead of many t-tests
Why ANOVA? From two means to many
The idea

A t-test compares two / three / many means. ANOVA stands for analysis of variance / average of values / a normal variable, and it extends that logic to compare three or more means, usually written as k group means.

It answers the question with one single F-test / t-test / z-test instead of many pairwise tests. Because it tests all groups at once, it is called an omnibus / paired / one-sided test.

Study (PREVEND): 500 Dutch adults take the RFFT cognition test. We ask whether mean RFFT score differs across the four education / age / blood-pressure groups (primary, lower & higher secondary, university).

The multiple-comparison trap

Why not just run a t-test on every pair? With 4 groups there are 6 / 4 / 12 possible pairs, so 6 separate t-tests.

Each test carries its own chance of a false positive / true negative / rounding error (about 0.05).

So with many groups you are likely to find a "significant" difference purely by chance / design / proof, even when none exists. ANOVA controls this by testing everything at once / one at a time / never.

P(≥1 false positive) = 1 − (0.95)6 ≈ 26% / 5% / 50%
Hypotheses and the F-statistic
What we are testing
H₀: μ₁ = μ₂ = μ₃ = μ₄

The null says all k group means are equal / different / zero, so there is no difference anywhere.

H₁: at least one μ differs

The alternative says at least one mean differs from the rest. Note it does not say which one. A significant result only tells us that at least one / every / no true mean is different.

We decide using the F-statistic / median / t-score: a large F is evidence of a real difference; an F near 1 / 100 / 20 is not.
The F-ratio: between over within
F = MS betweenMS within = variance between groupsvariance within groups
MS between is the variance between the group means, the signal / noise / cutoff. MS is short for mean square / margin of safety / most significant, another name for a variance.
MS within is the variance within each group, the noise / signal / mean in the data.
Each MS = its sum of squares divided by its degrees of freedom / sample mean / p-value. Big between and small within → large / small / negative F.
The two variances behind F
Numerator · MS between
Orange lines = distance from each group mean to the grand mean.
MSbetw = SSbetwk − 1 ,   SSbetw = Σ nj(xj − x)2

We square each group-mean-to-grand-mean gap, weight it by the group's sample size / median / variance, add them up, and divide by df. The further apart the group means, the larger / smaller / flatter this numerator, and the bigger the F.

Denominator · MS within
Purple lines = distance from each person to their own group mean.
MSwith = SSwithN − k ,   SSwith = ΣΣ (xij − xj)2

This measures the noise / signal / mean inside groups. More within-group scatter raises MS within, and since it sits in the denominator / numerator / exponent, that lowers F and gives less / more / certain evidence of a difference.

What makes F large or small
Three pictures: same four groups, very different F
Low F: small between, large within → F = low / high / medium
High F: large between, small within → F = high / low / medium
Medium F: large between and large within → F = medium / high / low

Tightly clustered points that still sit far apart (middle panel) are the strongest evidence: the small within-group spread makes it unlikely the gaps are just random variation / true signal / measurement units. Wide scatter (right panel) means the same group gaps could plausibly come from one / four / no shared distribution.

From F to a p-value, and how to run it in R
Load the data, then run aov()
library(rsr) # GRAPH Courses RSR package data(prevend) # outcome ~ grouping variable fit <- aov(RFFT ~ education, data = prevend) summary(fit) # Df Sum Sq Mean Sq F value Pr(>F) # education 3 115000 38333 73.3 <2e-16 *** # Residuals 496 259000 522
The first output row is the between / within / residual variation; "Residuals" is the within / between / total variation. Mean Sq = Sum Sq ÷ Df / F / N, and F value = 38,333 ÷ 522 / 496 / 3 ≈ 73.3.
Report it: "Mean RFFT scores differed significantly across education groups, F(3, 496) = 73.3, p < 0.001." This tells us at least one true mean differs / equals / is zero.
The F-curve turns F into a p-value
Convert F to a p-value using the F-curve for your degrees of freedom.
Between df = k − 1 = 4 − 1 = 3 / 4 / 500. Within df = N − k = 500 − 4 = 496 / 499 / 4.
The observed F = 73.3 sits far past the 2.62 cutoff, so p < 0.05 and the difference is significant / impossible / random.
Which pairs differ? Tukey's HSD follow-up
Tukey HSD follow-up

A significant ANOVA only says at least one mean differs, not which / how many / whether pairs. To find the specific pairs while still controlling the false-positive risk, run Tukey's HSD (Honestly Significant Difference / Distribution / Deviation).

TukeyHSD(fit) # diff lwr upr p adj # LowSec-Primary 14.78 7.93 21.63 0.000 # HiSec-Primary 23.16 16.40 29.92 0.000 # Univ-Primary 33.45 26.72 40.18 0.000 # ... (6 pairs in total)

Each row gives a pair's mean difference (diff), a 95% confidence interval (lwr, upr), and a p adjusted / raw p / sample size value already corrected for making several comparisons at once. Here all six p adj values are below 0.05, so every education group differs from every other.
