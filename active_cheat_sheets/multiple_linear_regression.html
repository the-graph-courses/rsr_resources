Multiple Linear Regression

Fitting and interpreting regressions with more than one predictor
Big idea

A regression with a single predictor can give a misleading slope when a third variable influences both the predictor and the outcome. Such a variable is called a confounder / residual / mediator.

Multiple linear regression fits several predictors at once. In R, each extra predictor is added to the formula with a + / * / ~ sign, as in lm(sick_days ~ washes + kids).

Each slope in the output is then read as the effect of that variable while holding the other predictors constant / positive / random. This is often phrased as "adjusting for" or controlling for / averaging over / correlating with the other variables.

The equation with two predictors
ŷ = b0 + b1x1 + b2x2
b0the intercept: the predicted Y when every predictor equals 0 / 1 / its mean
b1the change in Y for a one-unit increase in x1, holding x2 constant / at zero / maximal
b2the change in Y for a one-unit increase in x2, holding x1 constant
Worked example: does handwashing reduce sick days?
Fitting and reading the model
# mock survey: daily hand washes, kids at home, sick days next year mod1 <- lm(sick_days ~ washes, data = dat) # slope on washes: +0.66 mod2 <- lm(sick_days ~ washes + kids, data = dat) summary(mod2) Estimate Pr(>|t|) (Intercept) 12.33 washes -0.97 <0.05 kids 5.90 <0.05

The one-predictor model says each extra wash predicts 0.66 more sick days. After adding kids, the slope on washes flips to -0.97 / +0.66 / 5.90.

  • Holding kids constant, each extra wash predicts about one fewer / extra / total sick day.
  • Holding washes constant, each extra child predicts about 6 / 1 / 12 more sick days.
  • Prediction for 6 washes and 2 kids: ŷ = 12.33 + (−0.97×6) + (5.90×2 / 6 / 12) ≈ 18.3 / 24.2 / 12.3 sick days.
Adding kids fits one line per group: within each group, more washes now predict fewer sick days.
Confounding
Confounding and Directed Acyclic Graphs

A diagram of variables (nodes) joined by causal arrows is called a DAG / ANOVA / dummy. It maps assumed causal links and helps you spot confounding / correlation / residuals, among other things.

Showing causation is a high bar. Even after adjusting, claiming that our model shows that "handwashing causes fewer sick days" may still overclaim / understate / confirm what the model shows. Why:

  • Adjusting only closes paths through confounders we have measured / invented / removed; unmeasured / adjusted / significant ones may remain.
  • Reverse causation / association / correlation is still possible.

Safer phrasing is "significantly associated with, controlling for [your variables]". For a real causal claim, you ideally want a randomized experiment / regression / association or another well-designed intervention study.

The DAG for our example: kids causes both more washing and more sick days. Adjusting for kids closes this backdoor path.
Three or more predictors
Adding further predictors
mod3 <- lm(sick_days ~ washes + kids + commute, data = dat) Estimate Pr(>|t|) (Intercept) 11.80 washes -0.90 <0.01 kids 5.60 <0.01 commute 0.08 <0.01

Model 3 (mod3) fits sick days based on daily hand washes, number of kids at home, and commute minutes per day. Read the output as follows:

  • Reading a slope: holding washes and kids fixed, each extra minute on public transit predicts about 0.08 / 8 / 0.8 more sick days per year.
  • Prediction for 8 washes, 1 kid, and a 30-minute commute: 11.80 + (-0.90 / 5.60 / 0.08×8) + (5.60×1 / 8 / 30) + (0.08×30 / 8 / 1) = 12.6 sick days.
Comparing coefficients

A bigger slope is not necessarily a bigger effect, because the predictors use different units / hospitals / models:

  • Commuting an extra hour (60 minutes) a day is easy, and predicts 60×0.08 = 4.8 / 0.08 / 60 more sick days per year.
  • But nobody has 60 extra kids.

So the tiny per-minute slope of 0.08 / 5.60 / 4.8 and the large per-child slope of 5.60 / 0.08 / 60 cannot be compared head to head.
