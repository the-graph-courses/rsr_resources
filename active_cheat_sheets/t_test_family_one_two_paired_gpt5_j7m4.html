The t-test family: one-sample, two-sample, and paired

Choosing the right t-test, setting the direction, and reading the R output
Pick the right t-test
The shared idea

A t-test compares an observed mean / median / category or mean difference with what the null hypothesis / sample label / axis title says should happen.

The test statistic is a standardized gap: estimate minus null / null plus sample / p divided by df, divided by the standard error / standard deviation / confidence level.

t = estimate - null valueSE of estimate
A larger absolute t means the estimate is more standard errors / raw observations / confidence levels away from the null value.
Chooser rule
One-sample

One group mean vs a fixed target / second group / pair.

R: t.test(x, mu = m)

Two-sample

Two independent / repeated / fixed groups.

R: t.test(y ~ group)

Paired

The same units measured twice / in two samples / by category.

R: t.test(after, before, paired = TRUE)

Set hypotheses and direction
One-sample

Use when one sample is checked against a fixed value, such as a labelled 10g sugar claim.

Null: H0: μ = mu0 / xbar / df.

Formula: t = (x - μ0) / SE / df / p, with df = n - 1 / n + 1 / 2n.

sugar <- c(7.1, 8.5, 9.5, 10.4, 11.2, 11.8, 12.5, 13.3, 14.2, 15.4) t.test(sugar, mu = 10, alternative = "greater") # t = 1.697, df = 9, p-value = 0.062
Two-sample Welch

Use when the observations in group A and group B are separate people, babies, vials, or trials.

Null: H0: μ1 = mu2 / mu0 / xbar.

R's default two-sample test is Welch / paired / pooled only, which allows unequal variances.

SE = sqrt(s12/n1 + s22/n2)
t.test(bwt ~ smoke, data = birthwt) # Welch Two Sample t-test # t = 2.730, df = 170.1, p-value = 0.007
Paired

Use when each row has a natural before and after, twin, matched control, or repeated measurement.

Collapse each pair to one difference / category / variance: d = after - before.

Then test H0: μd = 0 / 1 / n with a one-sample t-test on the differences.

t.test(after, before, paired = TRUE) t.test(after - before, mu = 0) # same test # t = -2.76, df = 7, p-value = 0.028
Direction matters
QuestionAlternativeR setting
Any difference?H1: parameter != / > / = null"two.sided"
Greater than?H1: parameter > / < / = null"greater"
Less than?H1: parameter < / > / = null"less"

Choose the direction before / after / because of seeing the data. When in doubt, the cautious default is two-sided / greater / less.

R direction trap

For t.test(x, y, alternative = "greater"), R tests whether the mean of x / y / both tails is greater than the mean of y / x / alpha.

For a paired call t.test(after, before, paired = TRUE), "less" tests whether after minus before / before minus after / group 1 plus group 2 is below 0.

If lower values mean improvement, a before-to-after improvement often gives a negative / positive / zero mean difference when d = after - before.
Read the output
Output vocabulary
TermMeaningLook for
tGap measured in standard errors / raw data points / samples.Large absolute value means stronger evidence.
dfThe degrees of freedom / confidence / direction for the t curve.One-sample df is n - 1. Welch df is adjusted.
p-valueHow unusual this result is if H0 is true / proven / impossible.If p < alpha, reject H0.
CIPlausible values for the true parameter / sample / p-value.For differences, see whether 0 is inside.

Failing to reject H0 means the data were not strong enough; it does not prove / estimate / sample H0.

Evidence gets stronger when...
For the same question, bigger gaps, less noise, and more data push t farther from 0.

Because SE is in the denominator, evidence is stronger when SE is smaller / larger / unchanged. Larger samples usually make SE smaller / larger / undefined.

one-sample: s / sqrt(n) two-sample: combine both groups paired: use SD of differences
Practice checks
Fill the decision logic

A lab checks whether vials average the labelled 0.5 mL. This is a one-sample / paired / two-sample t-test, and the cautious alternative is μ != / > / = 0.5.

A study compares mean birth weight for babies from two separate parent groups. This is a two-sample / paired / one-sample t-test.

The same runners are timed before and after training. This is a paired / independent / one-sample t-test, because each after time is linked to a before time.

At alpha = 0.05, p = 0.02 means we reject / prove / ignore H0. At alpha = 0.05, p = 0.08 means we fail to reject / prove / automatically accept H0.

Correct or misconception?
"A paired t-test is just a one-sample t-test on the within-pair differences."
The paired test first computes one difference per pair, then tests whether the mean difference is 0.
"A small p-value proves that the null hypothesis is false."
A small p-value gives evidence against H0 under the test assumptions. It is not proof.
"If two groups are measured before and after, use a two-sample test because there are two columns."
The key is whether rows are linked. Same units before and after means paired.
