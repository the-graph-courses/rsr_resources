Check by thinking about your data and study design
SSample size
Common rule of thumb
  • Aim for at least 10 / 5 / 50 observations per parameter / predictor / outcome.
  • With fewer observations, estimates are imprecise, individual points have more influence, and diagnostic plots are harder to interpret.
Fix
  • Use fewer predictors.
UUncorrelated errors

Each residual should be independent of the others.

Watch for
  • clustered / censored / continuous data (for example clinics or schools).
  • Data ordered in time / space / cost (autocorrelation).
How to check
  • Think about the study design.
  • Compute the ICC for clustered data.
  • For time-ordered data, plot the residuals in collection order.
Fix
  • For clustered data: a mixed / additive / weighted-effects model, or cluster-robust standard errors.
  • For time-ordered data: a time-series / linear / logistic model.
Five assumptions checked by check_model() in the performance package
library(performance / diagnostics / modelcheck)
model <- lm(outcome ~ predictor, data = dat)
check_model / plot_model / test_model(model)  # draws the five panels below; a nicer version of base R's plot(model)
NNo multicollinearitymultiple regression only

Predictors should not carry overlapping / opposite / missing information.

How to check
  • Check each predictor's variance inflation factor (VIF / ICC / SSR).
  • A VIF near 1 is fine; above 10 / 2 / 100 is high.
Fix
  • Drop one of the overlapping predictors.
  • Or combine / square / center them into a single score.
Collinearity (VIF) plot
Violation
lm(height ~ age + grade): age and grade both have high VIF.
SShape (linearity)

Is the relationship really a straight line?

How to check
  • On the residuals-versus-fitted / observed / squared plot, the green smoother should stay near zero / one / the mean.
Fix
  • Transform the predictor or the outcome (for example with a log / z-score / rank or square root).
  • Or fit a non-linear / mixed / additive model.
Residuals vs fitted
Violation
lm(quiz_score ~ study_hours): the smoother bends away from the zero line.
HHomogeneity of variancehomoscedasticity, equal variance

The spread of the residuals should stay constant / increasing / normal across fitted values.

How to check
  • On the scale-location plot, the reference line should stay roughly flat. A line that slopes up / down from left to right means residual spread is increasing.
Fix
  • Use heteroscedasticity-robust / free standard errors.
  • Or transform the outcome.
Scale-location plot
Violation
lm(spending ~ income): residual spread increases as fitted values increase.
IInfluential points

An influential point is one that combines high leverage / variance / skewness and a large residual / intercept / p-value.

How to check
  • On the residuals-versus-leverage plot, look for points outside the dashed Cook's / Pearson's / Tukey's distance contour.
Fix
  • If the point looks like a data-entry error / cluster / winner (for example an impossible value), correct or drop it and refit.
  • If the point is real, consider reporting the results with and without / within / beyond it.
Residuals vs leverage
Violation
lm(chol ~ bmi): one observation lies outside the Cook's distance contour.
NNormality of residuals

The residuals should look roughly normal / uniform / skewed.

How to check
  • On the detrended Q-Q / P-P / R-R plot, points should stay close to the reference line and inside the confidence band.
  • Non-normality mainly matters in small / large / clustered samples. With large n, the CLT / VIF / DAG (central limit theorem) means the sampling distribution of the slope is still approximately normal.
Fix
  • Transform the outcome / predictor (for example with a log).
  • Inspect extreme residuals / slopes / VIFs and check whether they are data errors.
Detrended Q-Q plot
Violation
lm(er_visits ~ poverty): points in the right tail fall outside the confidence band.
Check with subject-matter knowledge (needed for causal claims)
EExogeneity

The predictor should be unrelated to the error term ("exogenous" means born outside / inside / after the system).

Watch for
  • confounding / collinearity / clustering
  • Reverse causation / coding / residuals
  • Measurement error / bias / model
How to check
  • No residual plot can certify this.
  • Use domain knowledge.
  • Draw a DAG / VIF / QQ.
If violated
  • The model is still valid for description and prediction.
  • The slope should not be read as causal / significant / linear.
Fix
  • Use a randomized experiment / observation / regression.
  • Or adjust / ignore / drop for confounders you can measure.
