Intro to Statistical Tests: P-Values

How to judge whether a sample result is surprising when the null story is true
Hypothesis testing
Two competing stories
H0: null

Says there is no real effect / a proven effect / clinical value.

H1: alternative

Says a true effect / typo / sample size does exist.

In hypothesis testing / data cleaning / bootstrapping, we ask which story is more consistent / colorful / confidential with the observed data, then return a p-value calculated under H0 / H1 / CI.

Examples in notation
Q1: Does the mean adult resting BP differ from 120 mmHg?
H0: μ = 120mean BP equals / differs from / is greater than 120 mmHg
H1: μ ≠ 120mean BP differs from / equals / matches 120 mmHg
Q2: Does the drug lower cholesterol differently than placebo?
H0: μdrug = μplacebodrug and placebo have the same / different / opposite mean effect
H1: μdrug ≠ μplacebodrug and placebo have different / the same / proven mean effects

H0 always contains the equality; H1 takes ≠ / = / ≈ (two-sided) or < / > (one-sided).

What a p-value says
The definition
p = P(result at least as extreme as observed | H0 is true)

A p-value is the probability of seeing a result at least as extreme / much smaller / exactly equal as the one observed, assuming the null hypothesis / alternative / confidence interval is true.

It ranges from 0 / -1 / 5 to 1 / 50 / 100. A small p-value means the data are unlikely / certain / required under H0; a large p-value means they are plausible / impossible / proven under H0.

Cholesterol example

Suppose the drug lowers cholesterol by 5 mmol/L on average and placebo lowers it by 2 mmol/L. The observed difference is 3 / 2 / 5 mmol/L.

H0 says there is no real difference / population / cutoff between drug and placebo. H1 says a true difference does / does not / might never exist.

If the software gives p = 0.02 / 0.20 / 0.50, then under the null there is a 2% / 20% / 50% chance of a result this extreme or more extreme.

That is evidence against / proving / ignoring the null, but it is not absolute proof.
Compare p with alpha
The significance level

The significance level, written alpha / beta / sigma, is the cutoff chosen before the test for how much chance is acceptable.

p < alpha

The result is statistically significant / automatically clinical / impossible, so we reject H0.

p ≥ alpha

The result is not statistically significant / proven false / always important, so we fail to reject H0.

0.01stricter
0.05common
0.10more lenient

By convention, alpha is often 0.05 / 0.50 / 1.00. Example: p = 0.02 with alpha = 0.05 is significant / not significant / proven; p = 0.08 with alpha = 0.05 is not significant / significant / proven.

Even when p = 0.02, there is still a 2% / 98% / 20% chance the result happened by chance. At alpha = 0.05, that leftover uncertainty is usually considered acceptable.
P-value as tail area
The curve shows what the statistic looks like across repeated samples if H0 were true. The shaded tail is the p-value.

The p-value assumes H0 / H1 / alpha is true. It is not the probability that H0 is true.

Interpretation traps
Reported studies: decide and explain
Study 1: Vaccine vs placebo
A trial tests whether a new vaccine reduces infection rates compared to placebo.
Reported: p = 0.003, α = 0.05
Decision: p < / > / = α, so we reject / fail to reject / prove H0.
Meaning: there is statistically significant / no / weak evidence the vaccine reduces infections at α = 0.05.
Study 2: Memory drug vs placebo
A trial tests whether a new drug improves memory scores compared to placebo.
Reported: p = 0.12, α = 0.05
Decision: p ≥ / < / = α, so we fail to reject / reject / disprove H0.
Meaning: not enough evidence / strong proof / no real effect to conclude the drug helps memory at α = 0.05.
Reminder: failing to reject H0 is not the same as proving H0. The effect could still be real but undetected.
Correct or misconception?
"p = 0.02 means a result this extreme would be rare if H0 were true."
Correct. The probability is conditional on the null hypothesis being true.
"p = 0.02 means there is a 2% chance that H0 is true."
The p-value assumes H0 is true. It does not directly assign a probability to H0.
"Not statistically significant means the effect definitely does not exist."
There may still be an effect, but the study did not provide enough evidence to reject H0.
"Statistical significance guarantees clinical importance."
A result can be statistically detectable but too small to matter in practice.
"Fail to reject H0 means we have proven H0 is true."
We only lack enough evidence to reject H0. That is not the same as proving no effect exists.
