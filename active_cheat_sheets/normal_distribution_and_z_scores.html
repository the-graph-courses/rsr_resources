The Normal Distribution & Z-Scores

The bell curve, the 68-95-99.7 rule, and how standardization puts values on a common z-scale
What a normal distribution is

A normal distribution is a special, bell-shaped density / frequency / linear curve that describes the tendency for data to cluster / scatter / spike around a central value. That central value is the population mean μ, which always sits in the middle / corner / edge of the curve, so most data fall near / far from / above the mean and fewer points land in either tail / peak / center. It arises naturally for many variables, such as height, weight, and exam scores.

The bell shape

Shape facts: it is unimodal / bimodal / skewed (a single peak) and symmetric / lopsided / flat about its mean. As a density curve, the total area / height / width under it always equals 1 / 0 / 50%. A variable that follows it is written X ~ N / U / P(μ, σ).

μ sets the position, σ sets the spread
The mean μ → position

The mean μ controls the position / spread / height of the curve along the axis. Increase μ and the whole curve slides to the right / left / top; decrease μ and it slides to the left / right / bottom.

The SD σ → spread

The standard deviation σ controls the spread / position / mean. A larger σ makes the curve flatter and wider / taller / narrower; a smaller σ makes it taller and narrower / wider / flatter. Because the total area must stay at 100% / 50% / 68%, extra width forces the height to decrease / increase / stay.

The 68-95-99.7 rule
The empirical rule

The 68-95-99.7 rule (the empirical / arbitrary / linear rule) approximates areas under any normal curve using whole standard-deviation steps from the mean:

• μ ± 1 / 2 / 3σ holds the central 68%  • μ ± 2 / 1 / 3σ holds 95%  • μ ± 3 / 2 / 4σ holds 99.7%.

These step sizes are rounded: for example, the exact 95% interval reaches ±1.96 / 2.00 / 1.64σ, not exactly 2σ.

Practice: for scores with μ = 80 and σ = 10, the area between 80 and 100 spans the mean up to 2 / 1 / 3σ above it. That is half of 95%, namely 47.5 / 95 / 34%.

Z-scores: standardizing values onto a common scale
The z-score and standardization

A z-score says how many standard deviations / means / units a value sits from the mean. One σ above the mean gives z = 1 / 0 / -1; two σ below gives z = -2 / 2 / -1; a value exactly at the mean gives z = 0 / 1 / -1. Converting raw data into z-scores is called standardization / normalizing / scaling.

z = x − μσ

In the formula, x is the observed / expected / average value, μ is the mean, and σ is the standard deviation / error / score. Example (blood pressure, μ = 130, σ = 20): a reading of 97 gives z = (97 − 130) / 20 = -1.65 / 1.65 / -0.65, i.e. 1.65 σ below / above / at average.

Standard normal distribution & the z-table

Standardizing normally distributed data produces the standard normal distribution: a normal distribution whose mean is 0 / 1 / 100 and whose standard deviation is 1 / 0 / 10. A z-table lists the proportion of values lying below / above / beside any z-score.

2.28% / 50% / 95%

A z of −2 maps to 0.0228, so 2.28 / 22.8 / 97.72% of values are smaller and 97.72 / 2.28 / 50% are larger. Because the curve is symmetric / skewed / flat, the negative-z rows also give you the positive-z areas.

Why this matters: compare across tests

Standardizing makes scores from different tests comparable. Two students sit different maths tests:

Max (class A)
His class had a mean score of 70 with a standard deviation of 10. Max scored 80, so z = (80 − 70) / 10 = 1 / 0 / 10.
Emma (class B)
Her class had a mean score of 140 with a standard deviation of 20. Emma scored 160, so z = (160 − 140) / 20 = 1 / 2 / 20.

Both score one σ above their own class, so relative to their peers they performed equally / very / poorly well.

Where this is heading
Why we learn this: the road to standard errors and the t-statistic

The z-score introduces a foundational statistical concept: (Observed Value − Expected Value) / Spread. This formula creates a unit-free ratio that tells you how surprising a number actually is.

As you advance, you will apply this exact same logic to statistical estimates (like sample means) rather than single data points:

  • The Spread: Instead of using standard deviation, you will divide by the standard error (a measure of how much an estimate fluctuates from sample to sample).
  • The Output: This calculation produces a z-statistic or a t-statistic, which will be used to make decisions about hypotheses.
