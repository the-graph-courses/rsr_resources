Intro to Logistic Regression

Modeling the probability of a yes/no outcome with a bounded S-curve
From linear regression to logistic regression
The big idea

Linear regression models a continuous / binary / categorical outcome Y. Logistic regression models the probability / count / variance of a binary / continuous / ordinal outcome (yes/no, 0/1).

Many health outcomes are binary by default: disease or not, cured or not, died or not. For this reason logistic regression is very common in public health / astronomy / geology research.

Regression still has two main jobs: prediction / decoration / deletion (estimate probabilities for new people) and understanding effects / ignoring effects / hiding effects (explain how predictors relate to the outcome).

Study (KLoSA): 4,184 Korean men aged 45+. We ask how the probability of weak grip (grip strength ≤ 27 / 37 / 17 kg) changes with age / height / income.
Revision: linear regression on grip strength

Before binarizing, lm(grip ~ age) gives a straight line. The age slope is about -0.38 / 0.38 / -8.82 kg per year: grip strength decreases / increases / stays flat with age.

That slope is fixed / random / undefined everywhere on the line: for every 1-year increase in age, Y changes by the same amount.

We then create weak_grip = 1 if grip ≤ 27 kg, else 0 / 1 / 27. Within 5-year age bands, the proportion with weak grip estimates the probability / variance / intercept in each band (about 3% / 79% / 50% at ages 45–49 and about 79% / 3% / 50% at ages 85+).

Why a straight line fails for probabilities
Two problems with fitting a line to proportions

Fitting lm(p ~ age) through band proportions can look reasonable, but:

  • Problem 1: the line predicts probabilities below 0 / exactly 0 / above 1 only or above 1 / below 0 / equal to 1 only. Probabilities must lie between 0 / -1 / 2 and 1 / 100 / 10.
  • Problem 2: a straight line has the wrong shape / color / sample size. A continuous predictor vs a binary outcome usually needs a gradual start, a steeper middle, then a flattening top.

The curve we need is S-shaped / U-shaped / flat, also called a sigmoid / linear / exponential curve. One common sigmoid is the logistic / quadratic / cubic curve.

Examples with the same shape: drug dose vs probability of cure; birth weight vs probability of survival.
The logistic curve stays between 0 and 1; a straight line can leave the valid probability range.
The logistic model and fitting it in R
The logistic function
P(Y = 1) = 1 / (1 + e−(b0 + b1 · x))
b0 (intercept) shifts the S-curve left / up / down only or right / sideways / nowhere along the x-axis.
b1 (slope on the log-odds scale) controls steepness / color / sample size of the S-curve. Larger |b1| → steeper transition.
By definition this equation cannot produce a probability greater than 1 / 2 / 100 or less than 0 / -1 / 0.5.

Fitted on KLoSA: b0 ≈ -8.82 / 0.117 / 55.7, b1 (age) ≈ 0.117 / -0.38 / 0.019. A positive age coefficient means older men have a higher / lower / zero predicted probability of weak grip.

glm() with family = binomial
# Logistic regression in R fit <- glm(weak_grip ~ age, family = binomial, data = klosa) summary(fit) Estimate (Intercept) -8.824 age 0.117

Use glm / lm / aov, not lm(), for a binary outcome. GLM stands for generalized linear model / general least model / grouped linear model.

Set family = binomial because the outcome has two / three / ten categories (0 and 1). In the summary, the test statistic is a z / t / F value (not a t value).

If b1 were exactly 0 / 1 / -8.82, predicted probability would stay constant / increasing / decreasing across age, just as a zero slope means no linear trend.

Using the model: prediction vs explaining effects
Prediction

To predict someone's probability of weak grip, substitute / ignore / square their age into the logistic equation, or use R's predict / summary / coef function.

Example readings from the fitted curve: at age 60, P ≈ 14% / 62% / 3%; at age 80, P ≈ 62% / 14% / 3%.

You are tracing a point on the S-curve from age on the x-axis up to the predicted probability / count / residual on the y-axis.

Understanding effects (harder than in linear regression)

Unlike linear regression, there is no fixed change in probability for a 1-year increase in age. The slope of the probability curve depends on where / whether / why you are on the S-curve.

So you cannot say "each year adds 0.05 to probability." Instead, each year adds a fixed b1 to the log odds / probability / grip strength, not to the probability itself.

How to interpret and report log odds is covered in later / never / linear regression lessons. That is often the hardest part of logistic regression.

Quick checks and watch-outs
Which model?

Model the probability of being cured / number who fell ill / average heart rate with logistic regression. Counts or continuous averages need a different method.

Best curve shape

For a continuous predictor and a yes/no outcome, the best-fitting shape is usually a sigmoid / straight / horizontal curve, not a straight / circular / vertical line.

Who is at higher risk?

With a positive age coefficient, an 80-year-old / 50-year-old / newborn has a higher predicted probability of weak grip than a younger man, all else equal.
