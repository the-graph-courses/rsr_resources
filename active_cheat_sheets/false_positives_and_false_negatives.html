False Positives, False Negatives & Power

The two ways a test can mislead you, and the power to catch a real effect
Two errors, two truths
Type I error → FALSE POSITIVEcrying wolf

A Type I error happens when we reject / accept / ignore a null hypothesis that is actually true / false / random. We announce an effect that does not really exist / vanish / repeat: a false positive / negative / neutral.

Three examples of a false positive

Courtroom: an innocent / guilty / repeat person is convicted.

Medical test: a healthy / sick / elderly patient is told they have the disease.

Height study: an unlucky sample makes two groups look different / identical / equal in height when they truly are not.

Type II error → FALSE NEGATIVEmissing the wolf

A Type II error happens when we fail to reject / reject / overturn a null hypothesis that is actually false / true / biased. We miss / prove / exaggerate a real effect: a false negative / positive / neutral.

Three examples of a false negative

Courtroom: a guilty / innocent / wealthy person is acquitted.

Medical test: a sick / healthy / young patient is told they are healthy.

Useful drug: a drug that truly works is abandoned / approved / patented because the study found no significant effect.

How likely is each?
If H₀ is TRUE (no real effect)
A false positive / true positive / false alarm (Type I)prob = α
A correct true negativeprob = 1−α
If H₀ is FALSE (a real effect exists)
A false negative / true negative / miss (Type II)prob = β
A correct true positive, the test's power / bias / spreadprob = 1−β
In a real study we don't know whether H₀ is true / proven / shuffled, so one “significant” result could be a true positive or a false positive / sure thing / true negative.
Power: catching a real effect
Power = the chance you catch a real effect

Power is the probability that we correctly reject / quietly accept / re-run a null hypothesis that is actually false / true / vague: the probability of correctly getting a small / large / negative p-value when a real effect exists.

power = 1 − β = P(reject H0 | H0 is false)

Power only applies when a real effect exists / disappears / repeats.

The less the two distributions overlap / shrink / rotate, the more power you have, because more results land past the cutoff.

The bigger the real effect / error / sample, the easier it is to detect.

You can always raise power by increasing the sample size / alpha level / effect. A power analysis / p-value / box plot tells you how many measurements to collect.
The two errors trade off: a stricter α gives fewer false positives but more / fewer / no false negatives. Only a bigger sample lowers both at once.
