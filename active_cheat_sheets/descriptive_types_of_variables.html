Descriptive Statistics 1: Types of Variables

Introduction to descriptive statistics and the types of variables
Big idea

Statistics has two branches. descriptive / inferential / creative statistics organises and displays data; inferential / categorical / predictive statistics uses sample data to draw conclusions about a population. The right summary, graph, and analysis depend on the variable type / name / colour.

Descriptive vs inferential statistics
DescriptiveInferential
summarise / predict / randomise & display dataUse a sample / guess / population to draw conclusions about the population
Tools: tables, charts / models / tests, summary statisticsTools: estimation, hypothesis testing / charting / sorting, regression
Population vs sample
PopulationSample
The entire / smallest / random group of interestA subset / superset / copy of the population chosen for study
Often impractical / illegal / easy to study entirelyPractical and feasible / expensive / random to study
True parameter (e.g. true mean)Sample statistic / variable / error (e.g. sample mean)

From the sample statistic we infer / ignore / invent the population parameter. This is the goal of inferential / descriptive / creative statistics.

A long ordinal with enough evenly-spread levels can often be treated as numeric / nominal. Conversely, a numeric scale (e.g. pain 0–10) can be binned into categories, making it ordinal / nominal.
