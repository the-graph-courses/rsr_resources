Intro to Logistic Regression

Model a binary outcome by predicting the probability that the outcome equals 1
From a continuous outcome to a binary outcome
The big idea

Linear regression models a continuous / binary / nominal outcome. Logistic regression models a binary / continuous / count outcome, such as disease yes/no, cured/not cured, or alive/dead.

The model predicts the probability / mean difference / sample size that the outcome equals 1. That prediction must stay between 0 / -1 / 50 and 1 / 2 / 100.

Two regression jobs: make predictions / categories / samples and understand how predictors relate to the outcome.
Worked example: KLoSA grip strength

In 4,184 Korean men aged 45+, grip strength in kg is continuous. The lesson turns it into a binary outcome:

weak_grip = 1 if grip ≤ 27 / 45 / 55.7 kg, otherwise 0

A value of 1 means weak grip / strong grip / missing grip; a value of 0 means not weak / unknown / older.

klosa <- klosa |> mutate(weak_grip = as.integer(grip <= 27))
Why an ordinary straight line is the wrong tool
The linear probability problem

Within five-year age bands, the proportion with weak grip estimates a probability / residual / coefficient. It rises from about 3% at ages 45 to 50 to about 79% / 27% / 3% at ages 85 to 90.

A straight line fails for two reasons:

  • It can predict values below 0 or above 1 / 0 / -1, which are impossible probabilities.
  • It imposes a constant / changing / curved slope, even though probability often rises slowly, then quickly, then slowly again.
Needed: an S-shaped sigmoid / straight / quadratic curve that stays within the probability bounds.
Straight line versus logistic curve
The logistic curve approaches 0 and 1 without crossing either boundary.

The curve is relatively flat / steep / linear near probabilities 0 and 1, and steepest through the middle.

Fit the curve and use it for prediction
The logistic function
p = 11 + e−(β0 + β1x)
OutputThe function turns any number into a probability between 0 / -1 / 1 and 1 / 2 / 100.
Shapeβ0 shifts the curve; β1 controls its direction and steepness / ceiling / units.

For the grip data, the fitted function is:

p̂ = 1 / [1 + e−(−8.82431 + 0.11683 age)]

Because the age coefficient is positive / negative / zero, older ages have a higher predicted probability of weak grip. If β1 were zero, the probability would stay constant / increasing / decreasing across age.

Fit it in R with glm()
weak_glm <- glm( weak_grip ~ age, family = binomial, data = klosa) summary(weak_glm) # Estimate Std. Error z value Pr(>|z|) # (Intercept) -8.82431 0.31925 -27.64 <2e-16 # age 0.11683 0.00476 24.57 <2e-16

Use glm() / lm() / aov(), short for generalized linear model, and set the family to binomial / gaussian / poisson.

The familiar table contains Estimate, Std. Error, a z value / t value / F value, and a p-value. The rows are the intercept and predictor coefficients.

Predicted probabilities

Substitute an age into the fitted equation, or use predict(), to obtain a predicted probability.

14%age 60
62%age 80
95%age 100

According to the fitted model, an 80-year-old has a higher / lower / equal predicted probability than a 50-year-old. Predictions far beyond observed ages are still extrapolations / residuals / categories and require caution.

Interpreting the age coefficient

Unlike a straight line, the logistic curve has no fixed change in probability / age / sample size for each one-year increase. The change depends on where you are on the curve.

Instead, each one-year increase adds the fixed coefficient β1 = 0.11683 to the log odds / probability / intercept. Odds and odds ratios are the next step.
