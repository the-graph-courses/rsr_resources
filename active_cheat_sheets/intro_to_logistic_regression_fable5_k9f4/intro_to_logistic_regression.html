Intro to Logistic Regression

From straight lines to S-curves: modeling the probability of a yes/no outcome
From continuous to binary
When the outcome is yes or no

Linear regression models a continuous outcome, like grip strength in kg. An outcome that takes only two values, such as cured or not cured, is called binary / continuous / ordinal. For such outcomes, the quantity that logistic regression actually models is the probability / count / mean of the outcome occurring.

Many health variables are yes/no by nature: got the disease or not, cured or not, died or not. In public health research, binary outcomes are actually more common / rarer / obsolete than continuous ones, which is why logistic regression is so popular in the field.

Running example: the KLOSA study

The KLOSA dataset (Korean Longitudinal Study of Aging) covers 4,184 Korean men aged 45+, with their age and their grip strength in kg, an indicator of muscular health measured with a hand dynamometer / goniometer / barometer.

Linear revision: lm(grip ~ age) fits a slope of −0.382, so each extra year of age predicts a 0.38 / 3.8 / 0.038 kg decrease / increase / plateau in grip strength, the same amount at every age.

Binarizing: using the European Working Group cutoff, men whose grip is at or below 27 / 45 / 12 kg are labeled as having a weak grip (coded 1 / 0 / NA), and everyone else is coded 0.

Why a straight line fails
Two problems with a straight-line fit

Cutting age into five-year bands / quartiles / pairs and computing the share with weak grip in each band gives values climbing from 3% at ages 45–49 up to 79 / 43 / 96% at 85+. Each proportion estimates a probability / residual / slope. Fitting a straight line through them has two problems:

  1. It predicts probabilities below 0 / 0.05 / 0.5 for the youngest men and above 1 / 0.95 / 100 for the oldest: impossible values, since probabilities must stay between those two bounds.
  2. It misses the shape: risk climbs gradually at first, faster in the middle, then flattens / accelerates / dips at old ages, because nearly everyone very old already has a weak grip.

A bounded curve with this gradual-steep-flat shape is called a sigmoid / parabolic / linear curve. The same shape appears whenever a continuous predictor drives a binary outcome: drug dose and the probability of cure, or birth weight and the probability of survival.

Straight line vs S-curve
Navy dots: share with weak grip per five-year age band. The dashed straight line exits below 0; the fitted logistic curve stays between 0 and 1.
What we need is a function that takes in the predictor and outputs an S-curve bounded between 0 and 1.
Fitting the S-curve
Logistic regression in R

Where linear regression used lm(), logistic regression uses the function glm / lm / log, which stands for generalized / graphical / grouped linear model:

m <- glm(weak_grip ~ age, family = binomial / gaussian / poisson, data = klosa)
summary(m)

We must set the family because logistic regression is not the only GLM. Here binomial says the outcome has two / three / many categories, 1 and 0.

The summary table mirrors lm(): an Estimate, a Std. Error, a z / t / F value (playing the role the t value played in linear regression), and a p value.

The logistic function
p = 11 + e−(β₀ + β₁·age)

For the KLOSA data, R fits intercept β₀ = -8.82 / -0.97 / 55.7 and age coefficient β₁ = 0.117 / 0.382 / 1.17.

Desmos intuition: making β₁ larger makes the climb steeper / flatter / taller, while changing β₀ slides the curve left or right / up or down / not at all along the x-axis. Whatever the values, the output can never leave the interval from 0 to 1 / 100 / 0.5. The fitting algorithm simply searches for the two numbers that make this S-curve best match the data.

Reading the output
The summary() table
            Estimate  Std. Error  z value  Pr(>|z|)
(Intercept)  -8.8243    0.3193     -27.64   <2e-16 ***
age           0.1168    0.0048      24.57   <2e-16 ***

Even before touching the equation, two facts are readable straight from this table. The age estimate is above zero, so the probability of weak grip rises / falls / oscillates with age. And its p value is far below 0.05, so the age effect is statistically significant / negligible / biased.

Which model for which outcome?
  • The probability of being cured of a disease is a job for logistic / linear / neither regression.
  • Average heart rate after exercise, a continuous measurement, is a job for linear / logistic / neither regression.
  • Whether a patient died before discharge, a yes/no outcome, is a job for logistic / linear / neither regression.
Using the model
Use 1: prediction (easy)

To predict a man's probability of weak grip, substitute his age into the fitted equation, or in R use the predict / summary / mutate function. Reading off the fitted curve, a 60-year-old has about a 14 / 5 / 48% chance, an 80-year-old about a 62 / 94 / 34% chance, and a 100-year-old about a 94% chance.

Use 2: understanding effects (harder)

On a straight line the slope is identical everywhere, but on an S-curve the slope keeps changing, so a one-year increase in age raises the probability by a different amount at different ages: there is no fixed / positive / small probability change per year. The quantity that does rise by exactly β₁ = 0.117 with each extra year, anywhere on the curve, is the log odds / R-squared / z value: the subject of the next lessons.

True or false?
"For a very old man, this fitted logistic equation could output a probability of 1.2."
False. The logistic function is bounded by construction: as age grows, the predicted probability approaches 1 but can never exceed it, and no plugged-in age can produce a value outside 0 to 1.
"If β₁ were exactly zero, the predicted probability of weak grip would be the same at every age."
True. Just as in linear regression, a coefficient of exactly zero means no relationship between the predictor and the outcome, so the prediction is flat across all ages.
"Since β₁ = 0.117, each extra year of age raises the probability of weak grip by 0.117."
False. Each extra year adds 0.117 to the log odds, not to the probability. The probability change per year depends on where you are on the curve: gentle at the ends, steep in the middle.
