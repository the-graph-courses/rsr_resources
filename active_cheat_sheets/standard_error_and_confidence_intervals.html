Intro to Statistical Tests: Standard Error & Confidence Intervals

How sample estimates get uncertainty bands before a statistical test
From sample to uncertainty
The estimation problem

In statistics, we usually cannot measure the whole population / sample / interval. We take a sample and use a sample statistic / parameter / label, such as x, to estimate a fixed but unknown population parameter / statistic / graph, such as μ.

If we drew a new random sample, the estimate would probably be a little different. That sample-to-sample movement is sampling variation / publication bias / rounding error.

The typical sample-to-sample spread of an estimate is the standard error / standard deviation / raw score. A range built from an estimate plus and minus a margin of error is a confidence interval / data table / p value.
Sample means and true mean

Each navy dot is one possible sample mean (x̄). The true mean (μ) is fixed, while the estimated sample mean varies across repeated samples of the same size.

Smaller movement means a more precise / biased / categorical estimate.

Standard error
standard deviation / standard error / sample size (SD)
Spread of individual data values
standard error / standard deviation / median (SE)
Precision of the estimate · SE = SD / √n

Both describe a kind of spread, but SD is the spread of the data while SE is the spread of the estimate. The dashed curve shows the wider data spread for comparison.

SD vs SE
Standard deviationStandard error
Spread of individual values / sample means / p values in the data distribution. Spread of the sampling distribution / raw score / data table of an estimate.
Stays roughly the same / smaller / larger as sample size grows. Gets smaller / larger / same as sample size increases.
If average sleep is 7 hours and SD is 1 hour, one person's sleep is typically about 1 hour / 7 hours / 0.2 hours from the mean. If repeated sleep samples have SE = 0.2 hours, a sample mean is typically about 0.2 hours / 1 hour / 7 hours from the true mean.
Describes variation / confidence / causation in the data. Describes precision / correlation / skew of the estimate.

So SD is about spread in the data / graph / model; SE is about uncertainty in the estimate / raw value / axis label.

Standard error of the mean
SE(x) = s√n

For a mean, SE equals the sample standard deviation / median / variance divided by the square root of the sample size / mean / label.

Example: A sample of n = 100 exam scores has s = 12 points.

SE = s√n
SE = 12√100
SE = 1.2 / 12 / 0.12 points
larger n → smaller SE larger SD → larger SE
Confidence intervals
How a CI is built
CI = x ± 1.96 × s√n
x is the sample mean / population variance / p value estimate.
1.96 is the critical value / sample size / mean estimate for a 95% normal-based interval.
s / √n is the standard error / raw score / null hypothesis.

Calculate one: n = 100 exam scores, x = 80, s = 12.

SE = 12 / √100 = 1.2 / 12 / 100
Margin of error = 1.96 × 1.2 = 2.35 / 1.96 / 12
95% CI = 80 ± 2.35 = 77.65 / 68 / 78.8 to 82.35 / 92 / 81.2 points
Remember the 68-95-99.7 rule: in a normal distribution, about 68 / 95 / 99.7% falls within 1 SD, 95 / 68 / 99.7% within 2 SDs, and 99.7 / 95 / 68% within 3 SDs. For a 95% CI, the precise z cutoff is 1.96; 2 is the quick approximation we usually learn for easy mental math.
What 95% confidence means

A 95% confidence level is about the long-run reliability of the method / parameter / one value. If we repeatedly took random samples and built an interval each time, about 95 / 50 / 5% of those intervals would contain the true value.

Most intervals cross the fixed true value. A few intervals miss it.
Quick interpretation checks
SE: true or false?
"A standard deviation describes the spread of individual observations."
True. SD is about individual data values, such as individual sleep durations.
"A standard error describes the typical distance between an estimated sample statistic and the true population value."
True. SE captures how far an estimate from one sample tends to fall from the true population value.
"Increasing n usually makes the standard error larger."
False. Because n is under the square root in the denominator, larger samples usually reduce SE.
"A standard error can only be calculated for the sample mean, not for other estimated statistics."
False. An SE can be found for many estimates: proportions, differences in means, regression slopes, odds ratios, and more, not just the mean.
"A standard error is generally smaller than the standard deviation."
True. Since SE = SD / √n, the SE is smaller than the SD for any sample with n > 1, which is essentially always in practice. They are only equal in the trivial case of n = 1.
CI: correct or misconception?
"There is a 95% chance that the true mean is in this exact computed interval."
Once the interval is computed, the fixed true value is either inside or outside it. The 95% refers to the method over repeated sampling.
"We are 95% confident that the true mean lies in this interval."
Correct, because "confident" is a technical word here. It means this interval came from a method that captures the true value about 95% of the time in repeated sampling.
"A wider confidence interval means the estimate is more precise."
A wider interval reflects more uncertainty, so it means a less precise estimate. Larger samples give narrower intervals.
