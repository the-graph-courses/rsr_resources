Intro to Logistic Regression

Modeling the probability of a yes/no outcome with an S-shaped curve
From continuous outcomes to binary ones
The big idea

Logistic regression models outcomes that are binary / continuous / ordinal (yes/no), and what it predicts is the probability / mean / residual of that outcome.

Linear regression suits a continuous / binary / categorical outcome (for example grip strength in kg). Logistic regression suits a binary / continuous / ordinal outcome (for example weak grip: yes or no).

In health research, many outcomes arrive already binary: disease or not, cured or not, died or not. That is one reason logistic regression is so popular / rare / obsolete in public health.
Turning a continuous outcome binary

Sometimes we start with a continuous measure and create a binary indicator with a clinical cutoff / average / intercept. Example: men with grip strength ≤ 27 kg are coded as having weak grip / strong grip / average grip.

In R that looks like coding 1 when the condition is true and 0 / 2 / NA otherwise. The new Y-axis then takes only those two values, and we model how the probability / intercept / residual of the "1" outcome changes with a predictor such as age / residual / intercept.

Why a straight line fails for probabilities
Two problems with a linear fit

One naive idea is to fit a straight line through age-band proportions. That approach has two big problems:

  • Problem 1: the line can predict probabilities below 0 / 0.5 / 1 or above 1 / 0 / 100. Probabilities must stay inside that interval.
  • Problem 2: a straight line usually has the wrong shape / color / sample size. With a continuous predictor, the probability often rises slowly, then faster / slower / randomly, then flattens.
The curve that matches that pattern is an S-shaped / straight / U-shaped curve, also called a sigmoid / parabola / histogram. Drug dose vs cure chance, or birth weight vs survival, often look like this too.
Line vs sigmoid
Rose dashed line leaves the legal [0, 1] band. Purple curve stays inside and flattens at both ends.
The logistic curve and fitting it in R
The logistic function
p = 11 + e−(β0 + β1 x)

This formula always returns a value between 0 / -1 / 0.5 and 1 / 2 / 100. The two coefficients reshape the S: β0 (the intercept / slope / residual) shifts it left or right, and β1 controls its steepness / color / sample size.

If β1 is positive, predicted probability increases / decreases / stays flat as x grows. If β1 were exactly 0 / 1 / -1, probability would stay constant / increasing / random across x.

Fit with glm(..., family = binomial)
# linear: lm(); logistic: glm() + binomial fit <- glm(weak_grip ~ age, family = binomial, data = klosa) summary(fit) # Estimate z value Pr(>|z|) # (Intercept) -8.82 -27.64 <2e-16 # age 0.117 24.57 <2e-16

We use glm / lm / aov (generalized linear model), not lm. Setting family = binomial / gaussian / poisson tells R the outcome has two categories. The summary still shows an intercept and a coefficient for age, plus a z value (like a t value) and a p-value / residual / mean.

What the model is for, and what comes next
Prediction is straightforward

Regression has two jobs: predict / delete / shuffle and understand effects / residuals / colors. For prediction, plug a person's age into the logistic equation (or use R's predict()) to get a predicted probability / residual / intercept of the yes outcome.

Example readings from a fitted age curve: age 60 → about 14% chance of weak grip; age 80 → about 62%. The S-curve never jumps past 1 / 2 / 10.
Effects are harder (preview)

In linear regression, β1 is a fixed change in Y for a 1-unit rise in x. On a logistic curve the slope is not fixed / always fixed / always zero: gentle near 0 and 1, steeper in the middle / ends / legend.

So we cannot say "each year adds a fixed amount of probability / intercept / sample size." Instead, each year adds a fixed β1 to the log odds / residual / sample mean. How to explain that clearly is the topic of the next lessons.

Check your instincts
"A fitted straight line that predicts a negative probability of disease for young people must be wrong, because probabilities cannot go below zero."
Sound. Probabilities are bounded between 0 and 1, so any model that predicts values outside that range is unsuitable for probability outcomes.
"Because the logistic curve is curved, the age coefficient in a logistic regression has no useful interpretation at all."
Misconception. There is still a single coefficient, but it is a fixed change on the log-odds scale, not a fixed change in probability. That interpretation is harder, and it is covered next.
"If you want to model the probability of being cured after a treatment, logistic regression is a natural choice."
Sound. Cured or not is a binary outcome, and logistic regression is built to model the probability of that yes/no event.
