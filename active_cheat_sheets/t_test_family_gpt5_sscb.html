Intro to Statistical Tests: The t-Test Family

Choose the test, write the hypotheses, read the R output, and interpret the decision
Choose the correct t-test
The big idea

A t-test compares one or two sample means / medians / ranges to a null claim. The null hypothesis is usually the status quo / research claim / sample mean: no difference, no change, or equality with a target.

The alternative hypothesis is the claim we need evidence for / against / unrelated to. The test statistic is the gap divided by its standard error / standard deviation / p value.

t = observed gap / SE

Large absolute t values mean the observed gap is many SEs from the null, so the data look less compatible with H0 / H1 / alpha.

Decision map
Ask what is being compared before writing any formula.

One group against a fixed claim uses a one-sample / two-sample / paired test. Two separate groups use an independent two-sample / one-sample / paired test. Same people, animals, or items measured twice use a paired / independent / one-sided test.

Study designQuestionNull hypothesisR call
One group vs a fixed target Is the true mean equal to mu0 / xbar / se? H0: μ = target t.test(x, mu = target)
Two separate groups Are the two population means equal / paired / fixed? H0: μ1 = μ2 t.test(y ~ group)
Same unit measured twice Is the mean difference / group size / target zero? H0: μd = 0 t.test(after, before, paired = TRUE)
Mechanics and direction
One-sample

Example: Bob claims his donuts average 10 g added sugar. We sample donuts and test whether the mean is above 10 g.

SE = s / √n
t = (x̄ - μ0) / SE

The target value is μ0. The sample spread is s / n / p, and the sample size is n / t / df.

R
t.test(sugar, mu = 10,
       alternative = "greater")
t = 1.70, df = 9, p-value = 0.062
Two-sample

Example: compare birth weights for babies whose mums did and did not smoke. The groups are separate, so use Welch's test by default.

SE = √(s1²/n1 + s2²/n2)
t = (x̄1 - x̄2) / SE

Welch allows the group variances to be unequal / identical / missing. A two-sided test uses both tails / one tail / no tails.

R
t.test(bwt ~ smoke, data = birthwt)
t = 2.73, df = 170.1, p-value = 0.007
Paired

Example: measure each patient's blood pressure before and after a drug. Pairing removes person-to-person noise by testing the within-person differences.

d = after - before
test d against 0

A paired t-test is really a one-sample / two-sample / chi-square test on the differences. H0 says the true mean difference is 0 / 1 / n.

R
t.test(after, before, paired = TRUE)
t = -2.76, df = 7, p-value = 0.028
Alternative direction

Use a two-sided / greater / less alternative when either direction would matter. Use a one-sided alternative only when the direction was chosen before looking at the data.

two-sided

H1: μ != / > / < target

alternative = "two.sided"

greater

H1: first mean is greater / smaller / equal

alternative = "greater"

less

H1: first mean is less / equal / two-sided

alternative = "less"

In t.test(B, A, alternative = "greater"), "greater" means the mean of B / A / both is greater than the mean of A / B / target.
From p to decision

Pick a significance level, often 0.05 / 0.50 / 5. If p is smaller than alpha, reject H0. If p is larger, fail to reject / prove / accept forever H0.

Practice and traps
Scenario practice
Scenario 1

A factory checks whether bolt lengths differ from the labelled 5 cm. Use a one-sample / paired / two-sample t-test with H1: μ != / > / < 5.

Scenario 2

Two separate drug groups are compared for pain relief. Use a two-sample / paired / one-sample test. H0 says the true group means are equal / different / paired.

Scenario 3

The same runners are timed before and after training. Use a paired / independent / one-sample test because each after value has its own before / placebo / target value.

H0: no real difference t: gap measured in SEs p: tail probability if H0 is true

Careful language: a small p-value does not prove H1. It says the data would be unlikely / guaranteed / ordinary if H0 were true.

Correct or misconception?
"For paired data, analyse the before-after differences, not two unrelated clouds."
Pairing keeps each subject as their own comparison, which removes between-subject noise.
"A p-value above 0.05 proves that the null hypothesis is true."
Failing to reject H0 means the test did not find enough evidence against it. It does not prove H0.
"More data can shrink the SE, making the same mean gap more convincing."
That is why Bob's 30-donut audit can be stronger than the 10-donut audit even with a similar mean.
