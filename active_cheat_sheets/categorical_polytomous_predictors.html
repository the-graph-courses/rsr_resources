Regression with a Polytomous Predictor

A categorical predictor with K > 2 levels becomes K − 1 dummy comparisons
Big idea

A polytomous predictor has more than two / five / ten categories (for example education: primary, lower secondary, higher secondary, university). We do not code it as a single 0,1,2,3 number, because that would force the jump between every neighbouring level to be exactly the same / largest / smallest. Instead R picks one reference level and creates K-1 / K / K+1 dummy variables, one for each remaining level.

The equation (education, primary = reference)
ŷ = b0 + b1·lower + b2·higher + b3·university

Each dummy is 1 / 10 / 0 only for its own level and 0 / 1 / 2 otherwise, so only one term is ever switched on. The intercept b0 is the mean of the reference / highest / average group, and each slope is that group's mean difference versus the reference.

Worked example: RFFT cognitive score by education
Each estimate is a difference vs the reference
# primary is the reference level mod <- lm(rfft ~ education, data = prevent) summary(mod) Estimate (Intercept) 40.94 educationLowerSecondary 14.78 educationHigherSecondary 32.13 educationUniversity 44.96

The intercept 40.94 is the mean for primary. To get any other group's mean, add its estimate to the intercept. Lower secondary = 40.94 + 14.78 / 55.72 / 40.94 = 55.72; higher secondary = 40.94 + 32.13 / 73.07 / 40.94 = 73.07; university = 40.94 + 44.96 / 85.9 / 40.94 = 85.9. So 44.96 means university scores 44.96 points above primary / university / the mean, not 44.96 in total.

Each red line is an estimate (mean vs primary); each point is a group mean.
Choosing the reference category
Clinical control

Sometimes the comparison you care about is "versus the control". In a drug trial, set the reference to the placebo / strongest / random or standard-of-care group, so every estimate directly reports the treatment effect.

Natural order

Sometimes the categories have a built-in order. Then pick the natural first or last level, like primary / university / lower education, so the comparisons climb an intuitive ladder from one end.

Extreme outcome

Sometimes you want every estimate to point the same way. Pick the group with the highest or lowest outcome / sample / label, so each effect reads cleanly as a gain over the worst or a deficit from the best.

Largest group

Sometimes precision matters most. Pick the group with the most observations, since every slope borrows the reference group's sample size, giving you tighter / wider / equal confidence intervals.

Quick practice
Predict a level

A model predicts resting heart rate (bpm) from weekly exercise, a 3-level predictor (sedentary, light, vigorous). N = 240.

# sedentary is the reference level mod <- lm(hr ~ exercise, data = fitness) summary(mod) Estimate Std.Error (Intercept) 78.0 ... exerciseLight -5.2 ... exerciseVigorous -9.8 ...

ŷ = 78.0 − 5.2·light − 9.8·vigorous. From this output, the predicted heart rate for a sedentary person is 78 / 72.8 / 68.2 bpm; for a vigorous person it is 78.0 − 9.8 = 68.2 / 72.8 / 78.0 bpm.

Read a coefficient

The light coefficient of −5.2 means light exercisers average 5.2 bpm lower than the sedentary / vigorous / average group, because that is the omitted reference level, not lower than the vigorous group.

Each row also has its own SE, t, p, and 95% CI, read just like the binary case: it compares that level against the reference.
