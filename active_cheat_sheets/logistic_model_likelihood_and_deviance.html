Logistic Regression: Likelihood and Deviance

How logistic regression scores model fit
Likelihood: scoring each prediction
Each observation contributes one score

A logistic model predicts a probability \(p_i\) for each person. The likelihood contribution asks how much probability the model assigned to what actually happened.

\[L_i = \begin{cases} p_i & \text{if } y_i = 1 \\[1pt] 1 - p_i & \text{if } y_i = 0 \end{cases}\]

If the outcome was 1 (for example, passed an exam), the contribution is p / 1-p / 0.5. If the outcome was 0 (failed), the contribution is 1-p / p / y.

Someone who failed with \(P(\text{pass}) = 0.2\) has contribution 0.8 / 0.2 / 1.2. Someone who passed with \(P(\text{pass}) = 0.9\) has contribution 0.9 / 0.1 / 1.9.

Overall likelihood multiplies the contributions
Overall \(L = 0.75 \times 0.60 \times 0.85 =\) 0.3825 / 2.2 / 0.75. Larger \(L\) means a better / worse / identical fit.

R chooses the coefficients by maximum likelihood estimation / least squares / ridge regression (MLE).

From likelihood to deviance
One chain of fit summaries
Likelihood
\(L = \prod L_i\)
Higher = better fit
→
Log-likelihood
\(\ell = \ln L\)
→
Deviance
\(-2 \times \ell\)
Lower = better fit
Why we take the natural log

Likelihoods multiply many numbers between 0 and 1, so \(L\) gets tiny fast. The natural log turns that product into a sum / quotient / product:

\[\ell = \ln L = \sum_{i=1}^{n} \ln L_i\]

Because \(\ln\) is increasing, maximizing \(\ell\) is the same as maximizing \(L\). Log-likelihood values are usually negative / positive / zero, and a less negative \(\ell\) means a better fit.

logLik(mod) # maximized log-likelihood
Deviance = −2 × log-likelihood
\[\text{Deviance} = -2 \times \ell\]

Multiplying by -2 / 2 / -1 flips the sign, so lower deviance means a better / worse / noisier fit.

If \(\ell = -120\), deviance is 240 / 120 / -240. Model A has deviance 50 and Model B has 40 on the same data, so Model B / A / neither fits better.

What summary() reports: null vs residual deviance
Read the two deviance lines
summary(mod) Null deviance: 8.3178 on 5 degrees of freedom Residual deviance: 4.9560 on 4 degrees of freedom

Null deviance comes from the intercept-only / saturated / full model (y ~ 1, no predictors). Residual deviance is the deviance of your fitted / null / empty model with predictors.

Degrees of freedom = number of observations minus number of parameters / outcomes / predictors only. With \(n = 6\) and two coefficients, residual df is 4 / 5 / 6.

Direction of fit

We care about deviance mainly because it lets us compare models / predict new y / compute odds. Null deviance is almost always larger / smaller / equal than residual deviance, because predictors usually improve fit.

Model X has residual deviance 12. Model Y has residual deviance 8 on the same data. Model Y / X / neither fits better because its deviance is lower.
True or false?
Mark each claim
"Degrees of freedom for residual deviance equal the number of observations minus the number of parameters."
True. Residual df is n minus the number of estimated parameters in the fitted model.
"We can use residual deviance to compare fit between any two models."
False. Residual deviance comparisons are for models fitted on the same data. Formal tests of the difference also require nested models.
"Null deviance is the deviance of the model that includes all of your predictors."
False. Null deviance comes from the intercept-only model. Residual deviance is for the fitted model with predictors.
