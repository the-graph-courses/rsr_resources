Regression with a Binary Predictor

When the predictor has exactly two groups, the line connects two means
Big idea

A binary predictor takes only two / three / many values, such as female vs male. Fitting lm(y ~ group) draws a line between the two group means / medians / totals, so the model still answers our three questions: is there a relationship? (is the gap significant / negative / rounded?), how big is it? (the size of the slope / intercept / residual), and we can predict Y from the group.

The equation & dummy coding
ŷ = b0 + b1 · x
xa dummy / random / squared variable: it is 0 / 1 / 2 for the reference group and 0 / 1 / 2 for the other group
b0the intercept = the mean of Y for the reference / second / largest group (where x = 0)
b1the slope = the difference / sum / ratio in means between the two groups
Worked example: birth weight by sex (births data, female = reference)
From means to coefficients
# female set as the reference level births <- births |> mutate(sex = fct_relevel(sex, "female")) mod <- lm(weight_kg ~ sex, data = births) summary(mod) Estimate Std.Error (Intercept) 3.180 0.026 sexmale 0.162 0.037

Female mean = 3.18 / 0.162 / 3.34 kg, and male mean = 3.18 + 0.162 = 3.34 / 3.18 / 0.16 kg. The row sexmale appears because male is the non-reference / missing / numeric level; the reference level female is folded into the intercept / slope / error and is not shown as its own row.

The slope is just the vertical gap between the two group means.
The reference category
Intercept (b0)

The intercept is the predicted Y when every dummy is 0 / 1 / 100, which is the mean of the reference group.

Switching the reference flips the sign

If we relevel so male is the reference, the row becomes sexfemale and the slope turns negative / positive / zero (−0.162), because the line now slopes downward.

The magnitude of the gap stays the same / larger / smaller: only the labelling changes, not the underlying relationship.

Practice & pitfalls
Quick practice

A model predicts hospital length of stay (days) from whether the admission was an emergency (1 = yes; 0 = no / planned admission). N = 240.

# planned admission is the reference level mod <- lm(stay ~ emergency, data = admissions) summary(mod) Estimate Std.Error (Intercept) 4.220 ... emergency 2.640 ...

ŷ = 4.22 + 2.64 · emergency

Planned admission is the reference level.

From this output, what is the predicted stay for a planned admission? 4.22 / 2.64 / 6.86 days. For an emergency admission? 6.86 / 4.22 / 2.64 days.

Slope is a difference

The slope of 2.64 means emergencies stay 2.64 days longer / shorter / total than planned admissions, not that emergencies stay 2.64 days in total.
