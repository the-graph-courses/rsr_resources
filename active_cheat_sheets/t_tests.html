Intro to Statistical Tests: The t-test Family

Choosing and reading one-sample, two-sample independent, and paired t-tests
What every t-test does
The shared logic

A t-test is a tool for comparing means / colors / categories. It asks whether an observed difference between means is larger than what random sampling variation / population census / data entry alone would produce, or whether that difference is real and significant / categorical / descriptive.

The data are reduced to a single t-statistic / median / mode, which is then converted to a p-value / sample size / box plot.

If the p-value is below the chosen cutoff, called alpha / beta / sigma (commonly 0.05), we reject / accept / prove the null hypothesis. If it is above alpha, we fail to reject / disprove / confirm the null.

All three t-tests follow this same logic. They differ only in which two means / the alpha level / the p-value cutoff are being compared.
Signal over noise: the t-statistic
t = estimate − null valuestandard error
The top is the signal: how far the observed mean sits from the null / mean / median value.
The bottom is the standard error, the noise / signal / bias we expect from sampling.
A larger t means the signal stands out more, which gives a smaller / larger / negative p-value.
How large a t must be to count depends on the degrees of freedom / margin of error / null mean, which grow with the sample size.
The three types of t-test
1 · One-sample

Compares one group's mean to a fixed target / second group / before value, a known or claimed value.

Example: pills labeled 500 mg. Is the batch's mean dose really 500?

H₀: μ = 500

The target value goes in the mu / paired / data argument.

# one mean vs a target t.test(pill, mu = 500)
2 · Two-sample independent

Compares the means of two separate groups made of different / the same / repeated individuals.

Example: pain relief in people given drug A vs people given drug B.

H₀: μA = μB

The null says the two means are equal / paired / zero, so there is no difference.

# two separate groups t.test(B, A)
3 · Paired (dependent)

Compares two measurements on the same individuals (or matched pairs).

Example: blood pressure before and after a drug, for each patient.

We run the test on each person's difference / total / maximum; the null is that the mean difference is zero / 500 / one.

H₀: μD = 0
# same units, measured twice t.test(after, before, paired = TRUE)

We set TRUE / FALSE / 0 for paired data. It equals a one-sample / two-sample / matched t-test on the differences.

Two-sided vs one-sided alternatives
Picking the alternative hypothesis

The null hypothesis is always an equality / inequality / range (for example μ = 500). The alternative sets which direction you test for.

Two-sided (H₁: μ ≠ target) detects a difference in either / only one / no direction, and it is the default / forbidden / rarest in R when you leave the argument out.

One-sided (H₁: μ > target, or μ < target) tests only one / both / zero direction.

Clinical work usually prefers / forbids / ignores two-sided tests: they catch both improvement and underperformance / sample size / rounding, and they reduce directional bias / measurement error / random noise because the direction must be fixed in advance.

t.test(x, mu = 500, alternative = "two.sided") # or "greater" / "less" for one-sided
Choose the alternative before / after / while you look at the data, never to chase a smaller p-value.
Where the p-value comes from
Two-sided: both tails count
One-sided: just one tail

For the same data, a one-sided test puts all of its rejection region in one / both / no tail. That is why a one-sided test is easier / harder / impossible to pass in its chosen direction, and why two-sided tests are the more stringent / lenient / random default.

Reading the t.test() output
Where the answer lives in R's output (two-sample)
Welch Two Sample t-test data: score by method t = 2.41, df = 38.2, p-value = 0.021 alt. hypothesis: true difference in means is not equal to 0 95 percent confidence interval: 1.12 8.44 sample estimates: mean in group online mean in group inperson 74.2 69.4
Here p = 0.021 is below α = 0.05, so we reject / fail to reject / prove H0: the two group means are not equal.
The null for a two-sample test is that the true difference in means is 0 / 74.2 / 4.8.
The sample estimate gap is 74.2 − 69.4 = 4.8 / 0.021 / 38.2 points.
The 95% confidence interval / null mean / row name (1.12 to 8.44) excludes 0, which agrees with rejecting H0.
Practice
Identify the test

1. A water utility claims the average lead level at household taps is 5 ppb. Inspectors sample taps across the city to see whether the true mean differs from 5 ppb. This is a one-sample / paired / independent t-test.

2. Mean final-exam scores are compared for students in an online section and students in an in-person section. This is a two-sample independent / paired / dependent t-test.

3. The same warehouse pickers are timed on a packing task before and after ergonomics coaching. This is a paired / one-sample / independent t-test.

4. Mean monthly electricity use is compared between households with solar panels and households without. This is a two-sample independent / paired / one-sample t-test.
