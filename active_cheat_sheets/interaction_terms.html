Interaction Terms in Regression

When the effect of one predictor depends on another
Big idea

An interaction means the effect of one predictor on the outcome depends on / equals / ignores the level of another predictor. A model without an interaction (an additive / interactive / unsaturated model) assumes that effect stays the same at every level of the other predictor: that is, the fitted curves or lines are parallel / identical / vertical and can differ only in their intercept / slope / residual. A model with an interaction lets that effect change with the second predictor, so different levels of the second predictor can have their own slope / intercept / mean.

Three models for one question
Building up: m1, m2, m3

Question: does blood pressure (BP) medication change the BMI→sysBP relationship?

Outcome: sysBP (systolic BP). Predictors: BMI and BPmeds (on BP medication or not).

ModelR formulaWhat it allows
m1sysBP ~ BMIone line for everyone / one group / outliers
m2sysBP ~ BMI + BPmedstwo lines, same slope / intercept / p value, different intercepts
m3sysBP ~ BMI + BPmeds + BMI:BPmeds / BMI-BPmeds / BMI/BPmedstwo lines, each with its own slope and intercept

The interaction term is written with a colon / comma / caret between the two variables. The shorthand BMI*BPmeds expands to BMI + BPmeds + BMI:BPmeds / BMI^BPmeds / BMI+BPmeds.

In the right panel the on-meds line starts higher but rises more slowly / steeply / randomly: the lines are not parallel / positive / linear.

Additive model (m2): parallel lines

Predicts systolic BP from BMI and BP medication, with one shared BMI slope for both groups (parallel lines).

lm(sysBP ~ BMI + BPmeds, data = dat) Estimate (Intercept) 88.84 BMI 1.65 BPmedsonMeds 29.24

The BMI slope 1.65 applies to both / neither / only medicated groups. The +29.24 gap is the same at every BMI.

Predict with the model. A person who takes blood pressure medication and has BMI = 30:

ŷ = 88.84 + 1.65·30 + 29.24 / 1.65 / 88.84 = 167.58

A person who is not on blood pressure medication and has BMI = 35:

ŷ = 88.84 + 1.65·35 = 146.59
Interaction model (m3): own slopes

Same predictors, plus BMI:BPmeds, so medication can change both the intercept gap and the BMI slope.

lm(sysBP ~ BMI + BPmeds + BMI:BPmeds, data = dat) Estimate (Intercept) 87.64 BMI 1.70 BPmedsonMeds 57.11 BMI:BPmedsonMeds -1.00

The reference group's slope is given by the plain BMI / BPmedsonMeds / (Intercept) row alone. To get the other group's slope, add the interaction / intercept / p-value row to it.

Predict with the model. A person who takes blood pressure medication and has BMI = 30. Use the slope from the on-meds row above:

ŷ = 144.75 + 0.70 / 1.70 / 57.11·30 = 165.75

A person who is not on blood pressure medication and has BMI = 35. Use the slope from the reference row above:

ŷ = 87.64 + 1.70 / 0.70 / 57.11·35 = 147.14
Interaction equation
ŷ = b0 + b1x + b2g + b3(x·g)
g1 = on meds, 0 = not on meds (reference)
b1slope of x for the reference / medicated / pooled group only
b2gap between the two lines at x = 0 / 25 / 30 (difference in intercepts)
b3how much the non-reference / reference / pooled slope differs from the reference slope; non-ref slope = reference slope + b3
Another example: education × sex on wage (female = reference)
R output

Predicts wage from years of education and sex, with educ:sex so the education slope can differ for males and females.

lm(wage ~ educ + sex + educ:sex, data = wages) Estimate (Intercept) 6.00 educ 1.70 sexmale 6.00 educ:sexmale 0.80

wage in $1000s per year; educ in years of education.

The reference group's slope is given by the plain educ / sexmale / (Intercept) row alone. To get the other group's slope, add the interaction / intercept / p-value row to it. Each extra year of education is associated with a larger / smaller / equal wage gain for males.

Predict with the model. A male with 16 years of education. Use the slope from the male row above:

ŷ = 12.00 + 2.50 / 1.70 / 0.80·16 = 52

A female with 16 years of education. Use the slope from the reference row above:

ŷ = 6.00 + 1.70 / 2.50 / 0.80·16 = 33.2
When to fit an interaction
  • It is well established / randomly chosen / always required in the literature (e.g. age × sex in growth charts).
  • It is your research question / residual / intercept: you test whether X's effect on Y depends on Z.
  • Design or biology strongly suggests effect modification / collinearity / extrapolation (e.g. antibiotic dose × bacterial resistance).
  • Otherwise default to an additive / saturated / null model: easier to read and more stable.
  • Do not fit all pairwise interactions and keep only significant ones: that is p-hacking / standardization / extrapolation and invalidates those p-values.
