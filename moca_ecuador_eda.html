Variable glossary

What each field measures in this dataset

ID ID

Unique participant identifier (e.g. MOCA0001). One row per adult assessed.

Edad Sociodemographic

Age in years at assessment. Sample ranges from young adulthood into older age.

Nivel Sociodemographic

Highest educational level attained (free-text in the raw file; chart uses normalized categories such as Primaria, Secundaria, Universitaria, Posgrado).

Años Sociodemographic

Years of formal education completed. Useful as a continuous education measure alongside Nivel.

Ocupación Sociodemographic

Employment / occupational status (full-time, part-time, retired, homemaker, unemployed, etc.).

Sexo Sociodemographic

Self-reported sex: Hombre, Mujer, or Otro.

Residencia Sociodemographic

Area of residence, mainly Urbano vs Rural (raw spellings cleaned for the chart).

Historial Clinical

Self-reported clinical history (e.g. none, hypertension, diabetes, cardiac, neurological, psychiatric). Free-text; grouped for display.

Alcohol Behavioral

Usual alcohol use frequency: never / occasionally / frequently (normalized from free-text).

Tabaco Behavioral

Tobacco use status: never, former smoker, occasional smoker, or daily smoker.

Actividad Física Behavioral

Usual physical activity intensity: sedentary, light, moderate, or intense.

Tiempo_minutos_segundos Process

Time taken to complete the mobile MoCA assessment (stored as mm:ss; plotted in minutes).

Cog_num Outcome

Not the classic 0–30 MoCA total. The data documentation calls this the numeric MoCA result, but values in the file run from 0 to 100 (higher = better). Treat it as the mobile app’s reported numeric performance score / scaled index, not the traditional MoCA points total unless the authors clarify otherwise.

Cog_ord Outcome

Ordinal performance band tied tightly to Cog_num in this file: below expected (0–42), slightly below (43–71), within expected (72–100). Labels are the app’s “expected range” categories, not a standard published MoCA cutoff like <26/30.

Source file: MOCA_TEST_ECUADOR.csv (semicolon-delimited, Latin-1). Dataset theme: cognitive impairment screening with mobile MoCA plus sociodemographic, clinical, and behavioral covariates.

Quick take: The sample is roughly balanced by sex, mostly urban, and middle-aged on average. Cog_num here is on a 0–100 scale (mean about 60; median 67), not classic MoCA 0–30. More than half fall slightly below or below the app’s “expected” band.
Important scoring note: A standard paper MoCA totals 0–30 points. In this dataset, Cog_num instead spans 0–100 and lines up exactly with the three Cog_ord bands (0–42 / 43–71 / 72–100). So these look like mobile-app scaled scores or percentile-like indices, not raw MoCA points. Use them as the file’s cognitive outcome, but do not interpret a value of 26 here as “MoCA = 26/30.”
